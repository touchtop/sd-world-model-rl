5.1 问题设定与符号
    定义 5.1 (状态空间): $\mathcal{S} \subseteq \mathbb{R}^n$
    定义 5.2 (世界模型): $\hat{T}: \mathcal{S} \times \mathcal{A} \to \mathcal{S}$
    定义 5.3 (结构化模型): 守恒律硬编码 $\hat{T}_{\text{SD}} = \Phi(s,a;\theta_{\text{conservation}})$
    定义 5.4 (无结构模型): 神经网络 $\hat{T}_{\text{BB}}(s,a) = s + f_\theta(s,a)$
    定义 5.5 (单步误差): $\epsilon_1 = \|\hat{T}(s,a) - T^*(s,a)\|_2$
    定义 5.6 (H步误差): $\epsilon_H = \|s_H^{\text{pred}} - s_H^{\text{true}}\|_2$

5.2 主要定理
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │ Theorem 5.1 (Error Growth Bounds)                                         │
    │                                                                             │
    │ 在假设 A1-A4 下，设 $\epsilon_1$ 为单步预测误差，则H步展开后：            │
    │                                                                             │
    │   结构化模型 (SD):  $\epsilon_H \leq \epsilon_1$                            │
    │   无结构模型 (BB):  $\epsilon_H \leq \epsilon_1 \cdot L^{H-1}$              │
    │                                                                             │
    │ 其中 $L \geq 1$ 为学习动力学函数的Lipschitz常数                          │
    │                                                                             │
    │ 推论: 当 $H \to \infty$ 时，BB误差指数爆炸，SD误差有界                     │
    └─────────────────────────────────────────────────────────────────────────────┘

    假设:
    - A1: 状态空间有界 $\|s\|_2 \leq B_s$
    - A2: 真实动力学 $T^*$ 和学习模型 $\hat{T}$ Lipschitz连续
    - A3: 结构化模型精确实现守恒律
    - A4: 单步误差有界 $\epsilon_1 \leq \epsilon_{\max}$

5.3 证明: 结构化模型的误差有界性
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │ Lemma 5.1 (守恒律防止误差传播)                                           │
    │                                                                             │
    │ 对于精确实现守恒律的结构化模型，预测误差不在守恒变量间累积。       │
    │                                                                             │
    │ 证明: 考虑库存更新 $I_{t+1} = I_t + A_t - S_t$                              │
    │   - 更新函数 $g(\cdot)$ 是硬编码的，无误差                                 │
    │   - 误差仅来自外生输入（到货、发货预测）                               │
    │   - 守恒律本身不放大误差                                                 │
    │                                                                             │
    │ 推论: $\|s_{t+1}^{\text{pred}} - s_{t+1}^{\text{true}}\|_{\text{conserved}} \leq   │
    │        \|s_t^{\text{pred}} - s_t^{\text{true}}\|_{\text{conserved}} + O(\epsilon_{\text{exogenous}})$ │
    └─────────────────────────────────────────────────────────────────────────────┘

    ┌─────────────────────────────────────────────────────────────────────────────┐
    │ Theorem 5.2 (SD误差界)                                                   │
    │                                                                             │
    │ 对于精确实现守恒律的结构化世界模型:                                       │
    │   $\epsilon_H^{\text{SD}} \leq \epsilon_1^{\text{SD}}$                      │
    │                                                                             │
    │ 证明: 对 $H$ 归纳。                                                        │
    │   - 基础情况 ($H=1$): 平凡                                               │
    │   - 归纳步骤: 守恒变量更新无误差放大；延迟变量为移位寄存器            │
    │   - 综合: $\epsilon_{k+1} \leq \epsilon_k \leq \epsilon_1$                  │
    │                                                                             │
    │ 直觉: 守恒律 $I' = I + \Delta_{\text{in}} - \Delta_{\text{out}}$ 是精确方程，   │
    │       其雅可比矩阵的奇异值为1（误差不放大）                               │
    └─────────────────────────────────────────────────────────────────────────────┘

5.4 证明: 无结构模型的误差指数增长
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │ Lemma 5.2 (神经网络误差传播 via Lipschitz常数)                           │
    │                                                                             │
    │ 设 $f_\theta: \mathbb{R}^d \to \mathbb{R}^n$ 为Lipschitz常数 $L_f$ 的神经网络:   │
    │   $\|f_\theta(x) - f_\theta(x')\|_2 \leq L_f \|x - x'\|_2$                   │
    │                                                                             │
    │ 证明: 对于ReLU网络，$L_f \leq \prod_i \sigma_{\max}(W^{(i)})$               │
    └─────────────────────────────────────────────────────────────────────────────┘

    ┌─────────────────────────────────────────────────────────────────────────────┐
    │ Lemma 5.3 (重复应用的指数增长)                                           │
    │                                                                             │
    │ 考虑残差动力学 $\hat{T}_{\text{BB}}(s,a) = s + f_\theta(s,a)$，Lipschitz常数 $L$: │
    │   误差演化: $\delta_{t+1} \leq (1 + L_f) \cdot \delta_t = \lambda \cdot \delta_t$ │
    │   H步后: $\delta_H \leq \lambda^H \delta_0 = \lambda^{H-1} \epsilon_1$              │
    │                                                                             │
    │ 证明: 由Lipschitz连续性，$\|f(x) - f(x')\| \leq L\|x-x'\|$                    │
    │   代入残差动力学并递归展开                                                 │
    └─────────────────────────────────────────────────────────────────────────────┘

    ┌─────────────────────────────────────────────────────────────────────────────┐
    │ Theorem 5.3 (BB误差界)                                                   │
    │                                                                             │
    │ 对于Lipschitz常数 $L = 1 + L_f > 1$ 的无结构世界模型:                        │
    │   $\epsilon_H^{\text{BB}} = \Theta(\lambda^H)$                              │
    │   其中 $\lambda = L$ 为指数增长率                                         │
    │                                                                             │
    │ 误差翻倍时间: $H_{\text{double}} = \frac{\ln 2}{\ln \lambda}$               │
    └─────────────────────────────────────────────────────────────────────────────┘

5.9 界紧致性分析
    ┌─────────────────────────────────────────────────────────────────────────────┐
    │ Lemma 5.4 (SD界紧致性)                                                   │
    │                                                                             │
    │ 对于SD模型 ε_H ≤ ε_1，该界在以下意义下紧致：                             │
    │   - 若动力学为 x_{t+1} = g(x_t) + B u_t，其中 ||g||_Lip = 1, ||B|| ≤ 1           │
    │   - 线性情况 x_{t+1} = x_t + u_t，常数偏差 d_t = d 对所有 t 成立              │
    │   - 此时 ε_t = d 恰好达到界                                                    │
    │                                                                             │
    │ 证明: 直接代入线性动力学，递归展开即可                                   │
    └─────────────────────────────────────────────────────────────────────────────┘

    ┌─────────────────────────────────────────────────────────────────────────────┐
    │ Lemma 5.5 (BB界: 最坏情况紧，平均情况可收缩)                             │
    │                                                                             │
    │ 最坏情况: E||e_H||² ≤ L^(2H-2) E||e_1||² (已达界)                           │
    │                                                                             │
    │ 平均情况: 若 Jacobian 谱半径 ρ < 1，则                                  │

    │                                                                             │
    │ 关键洞察: BB实际误差可能小于最坏情况界，但无法保证                     │

    │ 定义 5.7 (Rollout 回报):                                                   │
    │   给定世界模型 T̂, 从状态 s 执行动作 a 后, 按确定性策略 π 展开 H 步:       │
    │     R̂(s,a) = Σ_{t=0}^{H-1} γ^t r(ŝ_t, â_t) + γ^H V_ψ(ŝ_H)              │
    │   其中 ŝ_0 = s, â_0 = a, ŝ_{t+1} = T̂(ŝ_t, â_t), â_{t+1} = π(ŝ_{t+1})   │
    │                                                                             │
    │ 定义 5.8 (Q 估计量及误差分解):                                             │
    │   MCTS 对动作 a 进行 n_a 次独立 rollout, 定义 Q 估计量:                   │
    │     Q̂_{n_a}(s,a) = (1/n_a) Σ_{i=1}^{n_a} R̂_i(s,a)                        │
    │                                                                             │
    │   记 Q^π_H(s,a) 为真实环境中同策略同地平线的期望回报, 则误差分解为:        │
    │     Q̂_{n_a}(s,a) - Q^π_H(s,a) = bias(s,a) + noise_i                       │
    │                                                                             │
    │   其中:                                                                    │
    │   - bias(s,a) = E[R̂(s,a)] - Q^π_H(s,a)                                   │
    │     世界模型的系统性预测偏差, 由 T̂ ≠ T* 引起.                              │
    │     确定性模型 + 确定性环境 + 确定性策略下, 误差完全体现为 bias.           │
    │                                                                             │
    │   - Var[Q̂_{n_a}(s,a)] = σ²_rollout / n_a                                  │
    │     σ²_rollout = Var[R̂(s,a)] 为单次 rollout 回报的方差, 来源于:           │
    │     · σ²_env: 环境转移的固有随机性 (如随机需求)                            │
    │     · σ²_model: 模型本身的随机性 (如 ensemble/dropout)                     │
    │     当环境和模型均为确定性时, σ²_rollout = 0.                              │
    │                                                                             │
    │ 关键区分:                                                                  │
    │   - Bias 不能通过增加 n_a 消除, 只能通过改进模型或调整 H 缓解              │
    │   - Variance 可以通过增加 n_a 以 O(1/n_a) 速率消除                         │
    │   - 确定性模型+确定性环境+确定性策略: σ²_rollout = 0, 误差完全是 bias     │
    │                                                                             │
    │ ═══════════════════════════════════════════════════════════════════════════  │
    │ 5.10.2 SD 的零偏差性质 (从 §5.2 推导)                                     │
    │ ═══════════════════════════════════════════════════════════════════════════  │
    │                                                                             │
    │ Lemma 5.6 (SD 零偏差):                                                     │
    │                                                                             │
    │   若结构化模型 T̂_SD 精确实现守恒律 (假设 A3), 外生预测确定,               │
    │   且终值函数精确 (V_ψ = V^π 或 H 达终止步), 则:                           │
    │     bias_SD(s,a) = 0,  对所有 (s,a) 成立                                  │
    │                                                                             │
    │   证明:                                                                    │
    │   由假设 A3, 对于守恒分量 s_c:                                             │
    │     T̂_SD(s_c, a; exo) = T*(s_c, a; exo)                                   │
    │   当外生输入 exo 确定时, 给定相同的 (s, a) 序列:                           │
    │     ŝ_t = s_t 对所有 t = 0, ..., H                                         │
    │   因此:                                                                    │
    │     R̂_SD(s,a) = Σ γ^t r(s_t,a_t) + γ^H V_ψ(s_H) = Q^π_H(s,a)           │
    │   即 bias_SD = E[R̂_SD] - Q^π_H = 0.  □                                  │
    │                                                                             │
    │   若外生预测含不确定性, 则 bias_SD 仅由外生分量的预测偏差贡献,             │
    │   仍满足 |bias_SD| ≤ ε_1/(1-γ) = O(1) (由 Theorem 5.2).                   │
    │                                                                             │
    │ 推论 (SD 的 Q 估计精度):                                                   │
    │   在确定性环境 (σ²_env=0) + 精确守恒律 + V_ψ = V^π 下:                    │
    │     Q̂_SD(s,a) = Q^π_H(s,a) (精确, 无 bias 无 variance)                   │
    │   → 单次 rollout 即可获得精确 Q 值, N_SD = |A_eff| 足矣.                  │
    │                                                                             │
    │ ═══════════════════════════════════════════════════════════════════════════  │
    │ 5.10.3 BB 的 O(L^H) 偏差 (从 §5.4 推导)                                  │
    │ ═══════════════════════════════════════════════════════════════════════════  │
    │                                                                             │
    │ Lemma 5.7 (BB 偏差界):                                                     │
    │                                                                             │
    │   设 BB 模型 T̂_BB 的单步预测误差 ε_1 > 0, Lipschitz 常数 L > 1.          │
    │   设奖励函数和终值函数 Lipschitz 连续:                                     │
    │     |r(s,a) - r(s',a)| ≤ c_r ||s-s'||,  |V_ψ(s) - V_ψ(s')| ≤ c_V ||s-s'|| │
    │   则:                                                                      │
    │     |bias_BB(s,a)| ≤ c_r · ε_1 · γ · [1-(γL)^{H-1}] / [1-γL]             │
    │                      + γ^H · c_V · ε_1 · L^{H-1}              (γL ≠ 1)    │
    │                                                                             │
    │   当 γL > 1 时: |bias_BB| = O((γL)^H), 偏差随 H 指数增长.                 │
    │   当 γL = 1 时: 奖励项为 c_r · γ · ε_1 · (H-1).                           │
    │                                                                             │
    │   证明:                                                                    │
    │   由定义 5.7, ŝ_0 = s_0, â_0 = a_0, 故 t=0 项无误差.                     │
    │   由 §5.4 Theorem 5.3, t 步状态误差 ||ŝ_t - s_t|| ≤ ε_1 · L^{t-1}.      │
    │   BB 为确定性模型, R̂_BB(s,a) 对给定 (s,a) 是确定值:                      │
    │     bias_BB = R̂_BB - Q^π_H                                                │
    │            = Σ_{t=1}^{H-1} γ^t [r(ŝ_t,â_t)-r(s_t,a_t)]                  │
    │              + γ^H [V_ψ(ŝ_H)-V_ψ(s_H)]                                   │
    │   取绝对值, 由 Lipschitz 条件:                                             │
    │     |bias_BB| ≤ Σ_{t=1}^{H-1} γ^t · c_r · ε_1 L^{t-1}                   │
    │               + γ^H · c_V · ε_1 · L^{H-1}                                 │
    │   对求和项取几何级数闭式即得.  □                                           │
    │                                                                             │
    │ 关键对比:                                                                  │
    │   SD: |bias_SD| = 0 或 O(ε_1) (常数, 由 Lemma 5.6)                        │
    │   BB: |bias_BB| = O((γL)^H) (指数增长)                                    │
    │   → BB 的 Q 估计即使用无穷多次模拟也无法消除偏差                          │
    │   → BB 的偏差是不可约误差, SD 的偏差为零或可忽略                          │
    │                                                                             │
    │ ═══════════════════════════════════════════════════════════════════════════  │
    │ 5.10.4 效率定理                                                            │
    │ ═══════════════════════════════════════════════════════════════════════════  │
    │                                                                             │
    │ Theorem 5.4 (SD 自适应效率):                                               │
    │                                                                             │
    │   (i) 当 bias = 0 且 σ²_rollout = 0 (SD 在确定性环境, V_ψ=V^π):          │
    │       Q̂(s,a) = Q^π_H(s,a) 由单次 rollout 确定.                            │
    │       → N_sufficient = |A_eff|                                              │
    │       → 总计算成本 C_SD = |A_eff| · H                                      │
    │                                                                             │
    │   (ii) 当 bias = 0 但 σ²_rollout > 0 (SD 在随机环境):                     │
    │       Q̂(s,a) 无偏但有方差. 设 R̂(s,a) 为 σ²_rollout-次高斯且 i.i.d.,     │
    │       为使 Pr(|Q̂(a)-Q^π_H(a)| ≥ ε_mc) ≤ δ/|A_eff| (Union bound), 需:   │
    │       n_a ≥ 2σ²_rollout / ε_mc² · log(2|A_eff|/δ)                         │
    │       → N_SD = |A_eff| · n_a                                               │
    │                                                                             │
    │   (iii) 当 bias > 0 (BB):                                                  │
    │       增加 n_a 仅能消除方差, 不能消除偏差.                                 │
    │       Q̂ 的不可约误差下界: |E[Q̂]-Q^π_H| ≥ |bias_BB| 无论 n_a 多大.       │
    │       为使偏差可容忍, 需约束 H 使得 |bias_BB(H)| ≤ ε_bias:                │
    │         H_BB ≲ log(ε_bias/(c_r·ε_1·γ)) / log(γL)   (近似, γL>1)          │
    │       即 BB 的有效规划深度受限于模型精度.                                  │
    │                                                                             │
    │ ═══════════════════════════════════════════════════════════════════════════  │
    │ 5.10.5 加速界: H 维度 (bias 驱动) + N 维度 (条件性)                       │
    │ ═══════════════════════════════════════════════════════════════════════════  │
    │                                                                             │
    │ Theorem 5.5 (规划精度优势):                                                │
    │                                                                             │
    │   给定精度目标 ε_target, 定义计算成本 C = N · H.                           │
    │   SD 和 BB 分别选择最优 (N, H) 使总误差 ≤ ε_target:                       │
    │     ε_total = |bias(H)| + γ^H ||V_ψ-V^π|| + σ_rollout/√n_a · √(2log(2|A|/δ)) │
    │                                                                             │
    │   维度 1 - H 方向 (bias 驱动, 主要贡献):                                  │
    │                                                                             │
    │     SD: bias ≈ 0, 自由选择 H 仅需满足截断误差:                            │
    │         γ^{H_SD} ||V_ψ-V^π|| ≤ ε_trunc                                    │
    │         → H_SD = ⌈log(ε_trunc/||V_ψ-V^π||) / log γ⌉                      │
    │                                                                             │
    │     BB: 需同时满足截断误差和偏差约束:                                      │
    │         bias_BB(H) + γ^H ||V_ψ-V^π|| ≤ ε_target                           │
    │         由 Lemma 5.7, bias_BB(H) 随 H 指数增长 (γL>1),                    │
    │         而截断项 γ^H ||V_ψ-V^π|| 随 H 指数衰减.                           │
    │         两项对 H 的约束方向相反, 存在最优 H*_BB 使总偏差最小.              │
    │         当 |bias_BB(H*_BB)| > ε_target 时, BB 无法达到目标精度.            │
    │                                                                             │
    │   维度 2 - N 方向 (条件性):                                                │
    │                                                                             │
    │     情况 A: 确定性环境 + 确定性模型 (如 Beer Game):                        │
    │       SD 和 BB 的 rollout 均为确定性, σ²_rollout = 0.                      │
    │       N_SD = N_BB = |A_eff| (均只需每动作一次 rollout).                    │
    │       → N_BB/N_SD = 1 (N 方向无加速)                                      │
    │       → SD 的优势体现为: 在相同 H 下, bias_SD = 0 而 bias_BB > 0,         │
    │         SD 获得更精确的 Q 估计, 从而选择更优动作.                          │
    │                                                                             │
    │     情况 B: 随机环境 (σ²_env > 0), 确定性模型:                             │
    │       SD: σ²_rollout = σ²_env, bias = 0                                    │
    │       BB: σ²_rollout = σ²_env, bias > 0 (不可约)                           │
    │       N_BB/N_SD = 1 (方差相同), 但 BB 的 bias 是额外的不可约误差项,       │
    │       即使 N→∞, BB 的总误差仍 ≥ |bias_BB|.                                │
    │                                                                             │
    │     情况 C: 随机模型 (如 ensemble/dropout BB):                             │
    │       SD: σ²_rollout = σ²_env                                              │
    │       BB: σ²_rollout = σ²_env + σ²_model,BB                               │
    │       N_BB/N_SD = (σ²_env + σ²_model,BB) / σ²_env  (σ²_env > 0)          │
    │                 = 1 + σ²_model,BB/σ²_env                                   │
    │                                                                             │
    │   综合精度优势:                                                            │
    │     确定性环境: SD 可达 ε_total ≈ γ^H ||V_ψ-V^π|| (仅截断/bootstrap)     │
    │       BB 受限于 ε_total ≥ |bias_BB(H)| + γ^H ||V_ψ-V^π|| (不可约偏差)    │
    │       当 |bias_BB(H*_BB)| > ε_target, speedup = ∞ (BB 不可达)             │
    │     随机环境 + 随机模型:                                                   │
    │       speedup ≥ (1 + σ²_model,BB/σ²_env) (N 方向) + bias 优势 (H 方向)    │
    │                                                                             │
    │   关键洞察:                                                                │
    │   - SD 的效率优势本质上是 bias 优势: zero bias → 精确 Q 估计              │
    │   - BB 的 bias = O((γL)^H) 是不可约的, 增加 N 无法修复                    │
    │   - 在确定性环境中, SD 的 zero bias 使其在相同 (N, H) 下                  │
    │     获得更精确的 Q 估计, 从而做出更优的动作选择                            │
    │   - 在随机环境中, 若 BB 模型也含随机性, 则 N 方向有额外加速              │
    │                                                                             │
    │ ═══════════════════════════════════════════════════════════════════════════  │
    │ 5.10.6 误差预算分配                                                        │
    │ ═══════════════════════════════════════════════════════════════════════════  │
    │                                                                             │
    │   总规划误差上界:                                                          │
    │     |Q̂_{n_a}(s,a) - Q^π_H(s,a)| ≤ |bias| + σ_rollout/√n_a · Φ(δ,|A|)   │
    │     其中 Φ(δ,|A|) = √(2 log(2|A|/δ)) (Union bound + 次高斯浓度)          │
    │                                                                             │
    │   进一步分解 bias 来源:                                                    │
    │     |bias| ≤ ε_model + ε_bootstrap                                         │
    │     ε_model = Σ_{t=1}^{H-1} γ^t c_r ε_1 L^{t-1} + γ^H c_V ε_1 L^{H-1}  │
    │              (世界模型偏差, 含终端状态误差, Lemma 5.7 完整界)               │
    │     ε_bootstrap = γ^H ||V_ψ - V^π||                  (终值近似偏差)        │
    │                                                                             │
    │   给定目标总误差 ε_target:                                                 │
    │     SD: |bias| ≈ ε_bootstrap → 自由选择 H 使 bootstrap 偏差满足目标       │
    │     BB: |bias| ≥ ε_model(H) → 模型偏差约束 H 的选择                       │
    │                                                                             │
    │   当 |bias| ≥ ε_target 时:                                                 │
    │     模型偏差已超出误差预算, 需改进模型或减小 H.                            │
    │     此时 N_min = |A_eff| (至少覆盖所有可行动作).                           │

    │   环境: 确定性 (σ²_env=0), 模型: 确定性 (SD和BB均为确定性函数)            │
    │   V_ψ: 训练后的价值网络, ||V_ψ-V^π|| 量级远小于 V_max                     │
    │                                                                             │
    │   SD (情况 A, Theorem 5.4(i)):                                             │
    │     bias = 0 (Lemma 5.6), σ²_rollout = 0                                  │
    │     → Q̂_SD = Q^π_H (精确), N = |A_eff| = 50 足矣                         │
    │     → 实验: N 从 200 降至 50, 性能保持 (+5.3%)  ✓                          │

    │     σ²_rollout = 0 (确定性), 但 bias > 0 (不可约):                        │
    │       ε_model,reward = c_r · 0.345 · 0.99 · [1-1.054^9]/[1-1.054]         │

    │ 5.10.8 算法实现                                                            │
    │ ═══════════════════════════════════════════════════════════════════════════  │
    │                                                                             │
    │ 改进1: 自适应地平线选择 (bias 驱动)                                        │
    │   选择最小 H 满足: ε_model(H) + γ^H ||V_ψ-V^π|| ≤ ε_target               │
    │   其中 ε_model(H) = c_r ε_1 γ [1-(γL)^{H-1}]/(1-γL) + γ^H c_V ε_1 L^{H-1} │
    │   - SD: ε_model(H) ≈ 0 → H 仅受 bootstrap 偏差约束                       │
    │   - BB: ε_model(H) = O((γL)^H) → H 受模型偏差约束                        │
    │                                                                             │
    │ 改进2: 自适应模拟预算 (bias-aware)                                         │
    │   - bias ≈ 0 且 σ²_rollout = 0 → N = |A_eff|             (SD 确定性环境)  │
    │   - bias ≈ 0 且 σ²_rollout > 0 → N = O(σ²_rollout/ε²)   (SD 随机环境)    │
    │   - bias > 0 且 σ²_rollout = 0 → N = |A_eff|             (BB 确定性环境)  │
    │     (增加 N 无法消除 bias, 应转向改进模型或调整 H)                        │
    │                                                                             │
    │ 改进3: 选择性缓存 (守恒分量)                                               │
    │   由 Lemma 5.6, SD 的守恒分量转移是精确且确定的:                           │
    │   - s_c: 可缓存 (避免重复计算)                                             │
    │   - s_d: 外生预测, 仅更新 k << n 个参数                                   │
    │   - 每步成本从 O(n) 降至 O(k)                                              │
    │                                                                             │
    │ 伪代码:                                                                    │
    │   function SD_MCTS_ADAPT(s0, ε_target, δ):                                 │
    │     ε_model = estimate_model_bias()      // Lemma 5.7 闭式或采样估计       │
    │     H = min H s.t. ε_model(H) + γ^H ||V_ψ-V^π|| ≤ ε_target               │
    │     if ε_model ≈ 0 and σ²_rollout ≈ 0:  // SD 确定性环境                  │
    │       N = |A_eff|                                                          │
    │     elif σ²_rollout > 0:                                                   │
    │       ε_mc = ε_target - ε_model - γ^H ||V_ψ-V^π||                         │
    │       n_a = 2σ²_rollout/ε_mc²·log(2|A_eff|/δ) if ε_mc > 0 else 1         │
    │       N = |A_eff| · max(1, ⌈n_a⌉)                                         │
    │     else:                                                                  │
    │       N = |A_eff|                                                          │
    │     for sim in 1..N:                                                       │
    │       [MCTS rollout with cached transitions for s_c]                       │
    │     return argmax_a Q̂(a)                                                   │
    └─────────────────────────────────────────────────────────────────────────────┘

    理论精度优势 (Theorem 5.5 总结):
    SD 的效率优势来自两个维度:
    1. Bias 维度 (主要): |bias_SD| = 0 vs |bias_BB| = O((γL)^H)
       → SD 在任意 H 下获得精确 Q 估计; BB 的不可约偏差限制有效规划深度
       → 当 BB 无法满足 ε_target 时, speedup = ∞
    2. N 维度 (条件性): 仅当 σ²_rollout > 0 (随机环境或随机模型) 时,
       SD 的 σ²_model = 0 使其需要更少采样来消除噪声

    【实验B: 多步展开误差分析】(n=3 seeds) ⭐ **支撑定理的核心实验**
    数据来源: results/multi_step_rollout/20260215_213008/

    **研究目标**: 定量验证定理"结构先验将误差增长率从O(λ^H)降至O(1)"

    **数学推导**（需在§5理论部分展开）:

    ```
    Theorem: Error Growth under Autoregressive Rollout

    设f为状态转移函数，ŝ为预测状态

    无结构模型（神经网络）:
    |ŝ_{t+H} - s_{t+H}| ≈ O(λ^H)
    其中λ = ∂f/∂s > 1（Lipschitz常数）

    结构化模型（守恒律约束）:
    |ŝ_{t+H} - s_{t+H}| = O(1)
    因为守恒律保证误差不传播累积

    推论：当H → ∞时，无结构模型误差指数爆炸，
          而结构化模型误差有界
    ```

    **实验验证**（定量支撑定理）:

    | 模型 | 指数增长率λ | 误差翻倍时间 | 理论预测 |
    |------|-------------|--------------|----------|
    **SD** | **0.00%/step** | ∞ (不增长) | **O(1)** ✓ |
    **BB (ID)** | 6.35%/step | ~11步 | O(λ^H) ✓ |
    **BB (Backlog)** | 5.34%/step | ~13步 | O(λ^H) ✓ |
    **BB (Pipeline)** | 2.89%/step | ~24步 | O(λ^H) ✓ |

    **关键发现**：
    1. **定理验证**: SD的λ=0直接验证O(1)界；BB的λ>0验证O(λ^H)界
    2. **定量关系**: BB误差从H=1到H=50增长24.4倍 ≈ e^(0.0635×50) ≈ 24.0（与理论拟合）
    3. **实践意义**: 在需要长rollout的规划任务中，结构先验是必需的

    【实验C: 因果干预下的零样本鲁棒性】(n=3 seeds, budget=5000) ⭐ **支撑C3的核心实验**

    **核心发现：两层优势分解**

    SD-MCTS 的性能优势可被精确分解为两个独立的、互补的来源：

    1. **Layer 1 — 结构精度增益 (~2x, 主导效应)**
       即使不做任何干预更新（SD_no_update），SD 在所有干预下仍以 1.83x-2.38x
       领先 BB。这完全来自守恒律精确编码的先验优势。
       → **启示**: 在领域知识可获得的场景中，将其编码为归纳偏置的价值远超
         从零学习——即使数据充足（5000 步训练后优势仍不收敛）。

    2. **Layer 2 — 因果图编辑增益 (额外 16-26%, 增量效应)**
       符号图编辑在 capacity_shock 下额外降低成本 25.7%（1791→1331），
       在 comm_severed 下额外降低 15.9%（2216→1865）。
       SD_no_update 对照确认: 这一增益**专属于图编辑机制**，而非模型精度。
       → **启示**: 世界模型的"可编辑性"是一种独立于预测精度的架构属性，
         它赋予了模型**零样本适应突发结构变化**的能力。

    **三个启发性洞见**:

    ★ **洞见 1: 预测精度 ≠ 决策质量**
      comm_severed 下 SD_no_update 的 RMSE(11.46) 已接近 BB(13.87)——
      两者的预测误差仅差 17%。但策略成本差距却高达 **1.83 倍** (2216 vs 4059)。
      → 这揭示了一个深刻现象: **守恒律结构约束提供的决策改善**远超其在
        预测指标上的体现。可能的机制: 守恒律确保了状态空间中的**不变量守恒**，
        即使单步预测有误差，长期累积的状态仍满足物理约束，
        而 MLP 的误差则违反守恒律 → 在 MCTS 多步规划中级联放大。

    ★ **洞见 2: SD_no_update 的 RMSE 梯度映射了干预的"可观测性"**
      - none: RMSE = 0±0（无干预→无信息缺失→零误差）
      - capacity_shock: RMSE = 5.02±0.89（产能约束是"局部"修改→中等误差，低方差）
      - comm_severed: RMSE = 11.46±**4.18**（通信截断影响全局订单流→高误差，**极高方差**）
      → 这个梯度 (0→5→11) 恰好反映了**未编辑模型对干预的"认知盲区"大小**。
        它为"何时需要图编辑"提供了定量判据:
        当模型的未更新 RMSE 显著上升时，图编辑的价值就越大。
      → **方差维度的额外洞见**: comm_severed 下 SD_no_update 的 RMSE 标准差高达 ±4.18
        (三个种子分别为 5.94、12.38、16.06)，而 SD（图编辑后）始终为 0.00±0.00。
        这说明**全局性干预**（截断通信流）不仅使平均预测误差飙升，
        还使误差的**跨种子离散度**急剧增加——不同训练轨迹的 SD 模型
        对同一全局干预产生了差异巨大的"误判模式"。
        相比之下，一旦执行图编辑（SD），所有种子的 RMSE 归零且方差消失。
        → 图编辑不仅是"降低均值"的工具，更是**消除不确定性**的机制:
          它将模型从"依赖训练经验猜测"切换到"依据结构知识推演"，
          从根本上消除了预测行为对训练随机性的依赖。

    ★ **洞见 3: 对照实验的验证性——"none" 场景是自然安慰剂**
      在 none (无干预) 下，SD 与 SD_no_update 的性能几乎相同
      (914 vs 884, 差 -3.4% 属噪声范围，RMSE 均为 0)。
      → 这是一个**内建的安慰剂检验**: 当无需编辑时，编辑确实不产生虚假增益。
        这强化了 capacity_shock 和 comm_severed 下观察到的编辑增益的因果归因。

    此实验通过 SD_no_update 对照，将 SD-MCTS 的优势精确分解为两个可量化的来源。
    在已知干预类型和时间、且结构方程可用的前提下(scope condition)，
    SD-MCTS 展示了两个互补能力:
    (1) 守恒律编码提供约 2 倍的结构精度增益（不依赖干预更新即可获得）；
    (2) 符号因果图编辑提供额外 16-26% 的零样本适配增益。
    两者共同使 SD-MCTS 在 capacity_shock 下以 2.69 倍(=1331 vs 3585)领先 BB。
    这验证了 C3: **在因果图可编辑的前提下，符号化世界模型具有
    不可替代的零样本结构迁移能力**。

    【已完成实验：Principled Ablation Study】(n=1 seed, 修复后)
    数据来源: results/ablation/20260212_102554/results.json

    ┌─────────────────────────────────────────────────────────────────────────────┐
    │ Table 2: Ablation Study Across Scenarios (Return ↑, single seed)            │
    ├────────────────────┬──────────┬──────────────┬──────────┬──────────────────┤
    │ Scenario           │ SD-MCTS† │ BlackBox-MLP │ No-VNet  │ Greedy-1Step     │
    ├────────────────────┼──────────┼──────────────┼──────────┼──────────────────┤
    │ standard           │ **-659** │ -4301 (-85%) │ -762(-14%)│ -4761 (-86%)    │
    │ low_sample_shift   │ **-761** │ -5242 (-86%) │ -805(-6%)│ -5838 (-87%)     │
    │ long_horizon_delay │ **-2003**│ -43584(-95%) │ -2407(-17%)│ -38657 (-95%)  │
    └────────────────────┴──────────┴──────────────┴──────────┴──────────────────┘
    † Our method. Percentage shows relative degradation vs SD-MCTS.

    消融变体说明:
    | 变体 | 描述 | 测试假设 |
    |------|------|----------|
    | SD-MCTS (Full) | 完整模型 | 基准 |
    | BlackBox-MLP | MLP替代SD结构 | 结构先验贡献 |
    | No-VNet | 无神经价值网络 | 终端估计贡献 |
    | Greedy-1Step | 单步贪心(无MCTS) | 多步规划贡献 |
    | Wrong-Prior | 错误因果结构 | 结构正确性敏感度 |

    关键发现:
    1. **结构先验至关重要** (BlackBox-MLP消融):
       - standard场景: -4301 vs -659 → **85%性能下降**
       - long_horizon场景: -43584 vs -2003 → **95%性能下降**
       - 证明SD stock-flow结构是核心优势来源

    2. **MCTS多步规划必要** (Greedy-1Step消融):
       - 所有场景均86-95%性能下降
       - 特别在long_horizon场景，单步贪心完全失败(-38657)
       - 证明延迟效应需要前瞻性规划

    3. **价值网络视野扩展** (No-VNet消融):
       - standard: 14%下降，影响较小(短视野)
       - long_horizon: 17%下降(-2407 vs -2003)
       - 验证Theorem 3: VNet压缩无限视野尾部

    4. **场景特定发现**:
       - long_horizon_delay场景放大所有组件贡献
       - SD结构在long_horizon下提供21x优势(vs BlackBox)
       - 这符合理论预期：延迟越长，结构先验越重要

    Wrong-Prior分析 (错误因果结构):
    ┌────────────────────┬──────────┬─────────────┬────────────────────────────┐
    │ Scenario           │ SD-MCTS  │ Wrong-Prior │ 分析                       │
    ├────────────────────┼──────────┼─────────────┼────────────────────────────┤
    │ standard           │ -659     │ -509 (+23%) │ 异常：错误先验反而更好？   │
    │ low_sample_shift   │ -761     │ -1605 (-53%)│ 预期：少样本下错误先验受损 │
    │ long_horizon_delay │ -2003    │ -2611 (-23%)│ 预期：长视野放大先验误差   │
    └────────────────────┴──────────┴─────────────┴────────────────────────────┘

    standard场景wrong_prior异常说明:
    - 可能是单种子随机性导致
    - 需要多种子验证统计显著性
    - 但low_sample和long_horizon场景符合预期排序

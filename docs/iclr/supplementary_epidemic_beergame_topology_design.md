## 1. 方向选择

### 1.1 第一性原理判据

SD 世界模型���价值来自三点：把已知机理写进转移，使学习只需辨识少数参数；结构约束让长视界 rollout 不发散；参数与图结构可读、可编辑。据此，补充实验环境须满足：

1. 转移机理已知且为存量流量形式，但存在未知参数或参数漂移；
2. 决策质量由长视界的机理映射主导，而非组合搜索；
3. 关键相位的动力学是发散型的。Ramesh 与 Ravindran (L4DC 2023) ��结果表明，物理先验模型的回报优势主要出现在对初值敏感、误差快速累积的环境，非敏感环境里主要剩样本效率差异。这是经验动机，不是 SEIHR 必然属于该类的证明；§2.6 要求每次运行报告实际增长率以确认相位；
4. 存在自然的分布外参数变化和可用 do() 编辑的图结构，能复用 Beer Game 因果干预叙事；
5. 动作空间离散或可分解，能直接接入现有 MCTS。

XSokoban 违反 1、2：转移精确、零参数、难点是死锁与组合搜索。相关负结果保留为适用边界附录，DeepCubeA 基线不再推进。

### 1.3 选择流行病控制的理由

- 五条判据全部满足。隔室守恒是精确先验，黑盒模型会产生负人口或凭空感染，与 Beer Game Table 2 的物理违规对照同构。
- 潜伏期与住院延迟构成天然的延迟崩溃结构，医院容量阈值对应现有 delayed_collapse 环境的崩溃机制，价值网络扩展有效视界的论证有直接用武之地。
- 样本效率叙事成立：真实疫情只有几周观测窗口，黑盒模型学会指数动态需要大量数据，结构模型只需辨识少数参数。
- 分布外场景现成：变异株等价于 β 漂移，区域出行限制等价于对移动图做边删除，与论文中 capacity_shock、comm_severed 两类干预同构。
- 文献空缺：Bolshov 与 Chumachenko (PLOS One 2026) 的范围综述覆盖 2014 到 2025 年，512 条记录中纳入 13 项，仅 1 项加入基于模型的规划；Wan 等 (KDD 2021) 用贝叶斯 SIR 做蒙特卡洛 rollout。现有研究以无模型与策略梯度方法为主，明确把结构化模型与规划结合的研究较少。本实验不宣称该方向不存在先前工作，而是检验结构化 stock-flow 先验在低数据与干预 OOD 条件下的增益。
- 项目内部早有铺垫：two_papers.md §5.1 领域 C 已列出 SEIR。

## 2. 流行病环境规格

### 2.1 存量与单位

存量为人数，`x = (S, E, I, H, R)`，`S + E + I + H + R = N` 恒成立。时间单位为天；决策步为一周，内含 7 个日步。

状态向量：`(S, E, I, H, R, inf_week, Hmax_week, t, a_prev)`。`inf_week` 与 `Hmax_week` 是上一周的新增感染与住院峰值，使模型的 `predict_reward` 与环境奖励逐项一致；`t` 为周序号，与 Beer Game 状态末两维的约定一致。

### 2.2 概率化日转移

所有速率单位为天⁻¹，Δt = 1 天。每个隔室先计算总离开概率，再按速率比例分配到各出流，保证同一人同一天只发生一次转移。

| 隔室 | 总离开概率 | 出流分配 |
|---|---|---|
| S | `p_S = 1 - exp(-λ)`，`λ = β0 (1 - ε_a) I / N` | 全部到 E |
| E | `p_E = 1 - exp(-σ)` | 全部到 I |
| I | `p_I = 1 - exp(-γ)` | 到 H 比例 h，到 R 比例 1 - h |
| H | `p_H = 1 - exp(-ρ)` | 全部到 R |

确定性变体取转移核期望：`f_SE = S p_S`，`f_EI = E p_E`，`f_IH = I p_I h`，`f_IR = I p_I (1-h)`，`f_HR = H p_H`。随机变体对同一核抽样：`f_SE ~ Binomial(S, p_S)`，`f_EI ~ Binomial(E, p_E)`，`(f_IH, f_IR, ·) ~ Multinomial(I, [p_I h, p_I (1-h), 1 - p_I])`，`f_HR ~ Binomial(H, p_H)`。

更新：

```
S' = S - f_SE
E' = E + f_SE - f_EI
I' = I + f_EI - f_IH - f_IR
H' = H + f_IH - f_HR
R' = R + f_IR + f_HR
```

非负与守恒由构造保证，SD 模型不需要投影。数值监控每步记录 `|Σx' - N|`、最小隔室值、各转移概率是否落在 [0, 1]；任一越界记为运行失败标记，不做修正。

### 2.3 参数

| 类别 | 参数 | 说明 |
|---|---|---|
| 未知 θ | `β0` | 连续时间传播率，R0 = β0/γ |
| 未知 θ | `ε_1..ε_{K-1}` | 等级 k 的传播削减，`ε_0 = 0`；参数化 `ε_k = 1 - Π_{j≤k}(1 - δ_j)`，`δ_j = sigmoid(u_j)`，保证单调且落在 (0, 1) |
| 未知 θ | `h` | 离开 I 时进入 H 的分流比例，不是瞬时 hazard |
| 已知先验 | `σ, γ, ρ` | 潜伏期、感染期、住院期的倒数；A2-full-θ 中改为学习 |
| 报告观测变体 | `r_obs` | 未知；该变体中 h 固定为已知 |
| 已知常量 | `N, K_bed, c_a, w_inf, w_H` | |

全状态变体下 θ 维度为 K + 1，K = 5 时为 6。正值参数用 softplus，沿用 beer_game_sd_model.py 的约定。

### 2.4 观测与随机性变体

- 全状态：观测完整 x。用于完整 θ 辨识门槛。
- 报告观测：每周观测 `y_t = r_obs · Σ_d f_EI,d`（随机变体为二项抽样）与 H 精确值。固定 h 后，H 序列给出 I 的绝对尺度，β0 与 r_obs 可分离；若 h 也未知，(β0, h, r_obs) 在指数期存在尺度混淆。该变体用于检验部分观测下的结构预测与控制，不用于完整参数恢复。
- 确定性与随机：同一转移核的期望与实现。
- 公共随机数：随机变体的每次抽样使用按 (seed, episode, day, 隔室) 索引的均匀随机数流做逆变换抽样；同一 seed 下所有臂共享该流。

### 2.5 动作、奖励与视界

- 动作：`a_t ∈ {0, …, K-1}`，K = 5，`Discrete(5)`。
- 奖励按日聚合到周：

```
r_t = -( w_inf · Σ_{d=1..7} f_SE,t,d / N + w_H · max(0, max_d H_{t,d} - K_bed) / K_bed + c_a[a_t] )
```

- 环境、SD 模型 `predict_reward` 与 MCTS `reward_fn` 使用同一函数，输入为状态向量中的周聚合量。
- 视界 52 周；折扣与 Beer Game 主线一致。多目标 Pareto 分析不在本轮范围。

默认参数为 v1 冻结候选，待阶段 0 确认：N = 1e6，I0 = 100，E0 = 0，σ = 1/4 d⁻¹，γ = 1/6 d⁻¹，ρ = 1/10 d⁻¹，β0 = 0.5 d⁻¹，h = 0.03，K_bed = 3000，ε = (0, 0.2, 0.4, 0.6, 0.75)，c_a = (0, 0.05, 0.12, 0.25, 0.40)，w_inf 与 w_H 待定。

### 2.6 动力学相位与派生量

每次运行报告 R0 = β0/γ、早期增长率与倍增时间。含 E 隔室时，连续时间早期增长率是线性化矩阵 `[[-σ, β0], [σ, -γ]]` 的主特征值：

```
r = [ -(σ + γ) + sqrt((σ + γ)^2 + 4 σ (β0 - γ)) ] / 2
```

对于采用 `λ=β0 I/N` hazard 的概率化日核，逐日 SEI 线性化矩阵为 `[[exp(-σ), β0], [1-exp(-σ), exp(-γ)]]`（状态顺序为 E、I）；离散增长率定义为该矩阵最大特征值的对数除以 Δt。连续时间特征值仅作为近似诊断。默认参数下 R0 = 3，连续增长率约 0.148 d⁻¹、连续倍增约 4.7 天；离散核的增长率与倍增时间由实际矩阵计算。未干预相位为发散型；ε_a ≥ 0.6 时进入收缩相位。

### 2.7 可辨识性由策略覆盖决定

全状态确定性变体下：

- 等级 k 的周只能辨识组合 `β0 (1 - ε_k)`；β0 单独可辨识需要等级 0 的周；ε_k 需要等级 0 与等级 k 同时被使用；
- h 由 I→H 流量辨识，信息量与 I 成正比，低发病率下信号弱；
- 可辨识集合因此由策略决定。随机策略覆盖全部等级但代价高；压制策略只覆盖高等级且 I 小。这是 BVBw 所指"分布对辨识重要"的机械化表述，也是 §3.7 G2b 到 G2d 的预期失败模式。

每次辨识报告参数点估计与 CI、参数相关矩阵、局部 Fisher 信息条件数、可辨识组合。A2-full-θ 必须附此矩阵，否则"全部学习失败"无法区分结构不足与数据不足。

### 2.8 分布外与结构干预

| 干预 | 定义 | Beer Game 对应 |
|---|---|---|
| 变异株 | 第 `t_v` 周起 `β0 ← β0 (1 + Δ)`，Δ ∈ {0.3, 0.6} | 需求阶跃 |
| 免疫逃逸 | 新增流量 `R→S`，速率 ω | 新增边 |
| 医院容量冲击 | `K_bed ← 0.5 K_bed` | capacity_shock |
| 出行禁令（多区域） | 移动矩阵 `W_ij ← 0` 并重归一化 | comm_severed |

信息等级：

- intervention-known：类型、时间、幅度全部给出；
- intervention-type-known：只给类型与时间，幅度需再辨识。

两个等级下 A2 与 A1' 拿到逐项相同的信息：A2 以结构或参数编辑接收，A1' 以输入特征接收，即类型 one-hot、时间标志、已知时的幅度标量。缺失 R→S 边的先验失配定义为：环境 ω > 0，模型结构无该边且不被告知干预发生，与 intervention-type-known 区分。

### 2.9 多区域扩展

M 个区域，各自一组隔室，移动矩阵 W 行随机。区域 i 的感染力 `λ_i = β0 (1 - ε_{a_i}) Σ_j W_ij I_j / N_j`。动作为各区域等级，`MultiDiscrete([K]*M)`；MCTS 采用逐区域子步，保持分支因子为 K，折扣只在周期边界生效，见 §4.5。M ∈ {5, 10}。W 作为显式图结构，支持出行禁令的 do() 编辑。Libin 等 (ECML 2020) 的 379 区 metapopulation 与 Li 等 (IJGIS 2024) 的 74 子区模型是规模上限参考，本轮不追求。

### 2.10 参照与受限策略类上界

- oracle-parameter MCTS reference：同规划器、真参数，隔离辨识误差；
- oracle-parameter MPC reference：真参数、视界 H_mpc、动作序列束搜索；
- 受限策略类上界：分段常数策略，切换时刻在周网格上，至多 2 次切换，枚举量 C(51,2) × 5³ = 159 375 条 52 周轨迹；3 次切换视算力。仅在该策略类内称为上界。

三者互不为对方的上界，论文中不称理论最优。

### 3.4 预算与重复

- 交互预算以环境周计，网格 {52, 104, 260, 520, 1040}。

|---|---|
| 回报 | 固定预算回报、预算-性能曲线下面积、累计感染、医院溢出周数、干预等级分布 |
| 样本效率 | 达到 A4 回报 90% 所需交互量；未达到记为删失并报告达到比例；A4 回报为负时阈值改为随机策略与 A4 之间的 90% 分位 |
| 辨识 | θ̂ 轨迹、CI、相关矩阵、Fisher 条件数、可辨识组合 |
| 可靠性 | SD 臂：守恒误差、最小隔室值、概率越界次数。黑盒臂：投影前违反率、投影后违反率、投影 L1 修正量、逐隔室修正分量 |
| OOD | 两个信息等级下变异株、免疫逃逸、容量冲击的零样本回报下降 |
| 解释性 | 学到的 β0、ε_k、h 与真值对照 |
| 计算 | 每决策模型调用数、耗时 |

### 3.6 消融

- 先验失配：σ、γ 各偏离 ±30%；模���缺失 R→S 边而环境存在免疫逃逸。
- 视界与叶值：H ∈ {2, 4, 8}，叶值 {零, 价值网络}，延续 supplementary_experiments_plan.md 实验 A 的形式。
- 随机性：确定性对随机变体下的辨识误差与回报。
- 先验分层：A2、A2-full-θ、A1' 三者的差分。

### 3.7 门槛与预注册假设

| 门 | 条件 |
|---|---|
| G1 可靠性 | SD 臂：守恒误差 ≤ 1e-6·N，最小隔室 ≥ 0，转移概率在 [0, 1]，无数值修正；任一违反记运行失败。黑盒臂：报告投影前后违反率与修正量，不设通过阈值 |
| G2 辨识 | 全状态确定性变体，520 周内 β0、ε_k、h 进入 ±10% 且 CI 覆盖真值，分四层数据：G2a oracle 策略数据；G2b A2 自采数据；G2c 弱干预或低发病率数据；G2d 随机数据。允许"仅任务相关组合可辨识"的结论，须如实标注 |
| G3 规划 | A4 与 oracle-parameter MPC 差异在 CI 内；受限策略类上界单列 |
| G4 主对照 | H1 到 H4 |

预注册假设：

- H1：低预算下 A2 优于 A1 与 A1'；
- H2：变异株后 A2 优于 A3；A3 可编辑已知结构，不可更新参数；
- H3：随预算增加 A2 逼近 A4；
- H4：低数据或弱激励分布下 A2 不低于 A5；B_id 覆盖充分时差异缩小。若 A5 优于 A2，报告为在线辨识当前实现不足的负结果。

任一假设不成立即作为负结果报告，不通过调参改写主张。

## 4. Beer Game 拓扑扩展

### 4.1 动机

现有 Beer Game 结果已支持主主张，但拓扑固定为四级串行链。扩展的意义：一是检验结构先验在更大、更复杂拓扑上是否仍带来样本效率与 OOD 优势，直接回应 GNGG 的核心质疑；二是拓扑迁移是"结构作为可插拔先验"的最强检验；三是 gym-invmgmt (2026) 与 OR-Gym 提供了可对齐的拓扑规范与运筹基线。

### 4.2 现状

beer_game_env.py 与 beer_game_sd_model.py 固定四级串行、两槽订单与发货管道、26 维状态；学习量为需求阶跃的三个标量；动作为 9^4 平铺或逐级顺序。causal_intervention 脚本实现 capacity_shock 与 comm_severed 两类干预。

BeerGameEnvSequential 未被任何已发表结果使用（rebuttal 记录 Beer Game 使用 81 个联合动作，即平铺模式），且原实现无法实例化：子类定义了无 setter 的 observation_space 属性，父类 __init__ 对其赋值触发 AttributeError。已于 2026-09-11 改为实例属性，不影响任何既有结果。

### 4.3 图通用 stock-flow 模型

拓扑 `G = (V, E)`，供货边 `e = (u→v)` 带发货延迟 `L_e`，反向订单边带信息延迟 `τ_e`。

| 元素 | 定义 |
|---|---|
| 存量 | 节点库存 `I_v`；按下游边的欠单 `B_e` |
| 管道 | 每条边长度 `L_e` 的发货移位寄存器、长度 `τ_e` 的订单移位寄存器 |
| 外部需求 | 零售节点 `D_v(t)`，由需求剖面参数刻画 |
| 生产 | 源节点产能 `cap_v` |
| 分配规则 | 多下游时库存按欠单比例分配。这是环境真值的一部分，模型已知；优先级分配作为规则失配测试 |
| 多供应商 | 入度大于 1 的节点按固定等比例拆分订单，模型已知 |
| 成本 | `Σ_v h_v I_v + Σ_e p_e B_e` |

更新：`I_v' = I_v + Σ_{e∈in(v)} arrivals_e - Σ_{e∈out(v)} ship_e`，管道移位，截断非负。状态维度 `2|V| + Σ_e (L_e + τ_e) + 2`。

参数设定：

- 共享参数：所有零售节点共享需求剖面三参数，θ 的全局维度与 |V| 无关；
- 节点特定参数：每个零售节点独立三参数，θ 维度为 3 × 零售节点数，用于测量参数维度增长带来的退化。

两设定都报告 SD 与黑盒模型参数量随 |V| 的曲线。延迟与产能视为已知。

### 4.4 拓扑集

| 编号 | 结构 | 节点 | 边 | 最长路径（节点） | 最大入度 | 最大出度 | 零售节点 | 用途 |
|---|---|---|---|---|---|---|---|---|
| T1 | 串行 | 4 | 3 | 4 | 1 | 1 | 1 | 现有结果，冻结 |
| T2 | 串行 | 8 | 7 | 8 | 1 | 1 | 1 | 深度扩展 |
| T3 | 分叉 1-2-4 | 7 | 6 | 3 | 1 | 2 | 4 | 多零售与分配规则 |
| T4 | DAG 2-3-5 | 10 | 11 | 3 | 2 | 3 | 5 | 多源与交叉边 |
| T5 | DAG 3-6-9 | 18 | 24 | 3 | 2 | 3 | 9 | 规模审计 |

默认所有边 `L_e = τ_e = 2`；T4、T5 另设异质延迟 {1, 2, 3} 变体。拓扑以项目内 YAML 定义，与 gym-invmgmt 的 DAG 规范对齐，不引用其默认实例。

T5 只做规模审计：图通用 rollout 一致性、短视界规划、模型调用数与耗时随 |V| 的曲线、两种参数设定的维度扩展、T1 学习后向 T5 的结构迁移审计。不进入四臂、OOD 与主统计表。正式拓扑主表为 T1 到 T4。

### 4.5 动作空间与顺序子步

- 逐节点子步，分支因子 9，每周期 |V| 个决策；9^8 及以上的平铺不可行。
- 子步状态含子步索引与已提交订单；中间子步奖励为 0。
- 折扣只在周期边界生效。现有 mcts.py 在每条树边乘 γ，子步模式下需要子步感知折扣：中间子步 γ_sub = 1，周期末子步 γ。以规划器包装实现，不改 mcts.py 既有语义。
- 搜索深度同时以节点决策数与周期数报告，只有周期数与原论文的 H 可比。

### 4.6 实验

1. 样本效率随拓扑规模：SD 对黑盒在 T1 到 T4 的预算曲线，共享与节点特定两种参数设定分别报告。
2. 零样本拓扑迁移：在 T1 上学 θ，编辑图后直接在 T3 评估，与在 T3 上重学对比。
3. 更大图上的因果干预：节点产能冲击、边删除、延迟变化，延续 capacity_shock 与 comm_severed 的协议。
4. 运筹基线：base-stock、(s, S)、滚动视界 LP、PPO。

- 容量条件预测 TVA 决策正式批次：10 seeds、64 simulations、A2 与原纯 rollout 配对完成，结果为 `results/iclr_epidemic_capacity_prediction_tva_formal_20260912`。A2 冲击后回报均值由纯 rollout 的 −57.96 提升至 −56.82，配对提升 +1.14，95% bootstrap CI [−1.57, 3.85]；方向改善但区间跨 0，暂记为机制支持信号，不宣称显著性能提升。A1′、A5 两个版本同步完成，作为参照。
- TVA 误差诊断：在 capacity 冲击轨迹的 weeks 8–51 上，预测 TVA 对 A2 的 continuation-return MAE 为 2.81、偏差 +2.25（正偏差表示高估未来回报）；冲击早期 weeks 8–19 的 MAE 为 7.69，后期仅 0.92。该早期系统性高估可解释 A2 未及时增加干预；当前主要瓶颈是容量冲击后的分布外价值校准，而非终端状态缺少长期信息。下一步应做冲击后再校准/风险敏感 TVA，并核对叶值引起的根动作排序变化。
- 早期偏差校准 smoke：使用 seeds 6–7 估计早期高估偏差（+8.54）并在 weeks 8–19 对叶值作保守校正，留出 seeds 8–9 的 capacity 回报反而恶化。该结果表明简单的标量偏差修正会改变动作排序但未必改善控制，后续必须检查动作级 `Q_H`/搜索值，而非继续调整全局偏置；该 smoke 不进入正式证据。
- 动作级诊断：在 A2+预测 TVA 的 capacity 轨迹中，用“替换当前动作、随后重放原策略”评估冲击早期动作，120 个状态中 62.5% 选择了该条件下的最优动作，平均回报差仅 −0.014。未发现系统性动作排序崩溃；TVA 的剩余问题更接近长期目标权衡和训练分布校准，而非单一动作选择错误。
- TVA 语义审计（2026-09-12）：完整核对论文 Eq. (4)–(5)、Beer Game 入口及当前流行病入口后确认，论文 TVA 要求以 MCTS 根节点访问分布加权的 \(\hat Q_H\) 构造 `V_search`，并与 target-network TD 项联合训练；Beer Game 现有入口和流行病当前实现均主要以 episode return 回归训练 value network，尚未实现该 TVA。此前所有流行病“TVA” smoke/formal 结果均降级为普通 return-value proxy 诊断，不得称为 TVA 证据或用于否定 TVA。
- TVA 修订前置条件：先在 Beer Game 既有实现中复核并固定 `V_search`、温度系数、stop-gradient、TD target network、shared-prior/per-seed-finetune 和容量/奖励上下文的完整语义，再将同一实现移植到流行病。未满足这些条件前，不运行新的正式 capacity TVA 批次。

### 7.8 TVA 的第一性原理定义与流行病修订方案

TVA 的本质是有限步 SD 状态推演的终端长期价值补偿器，而不是某一种 MCTS 损失，也不依赖某一种决策器。给定有限推演深度 \(H\)：

\[
\hat{s}_{t+H}=P_\theta^{(H)}(s_t,u_{t:t+H-1}),\qquad
\hat G=\sum_{k=0}^{H-1}\gamma^k r_{t+k}+\gamma^H V_\psi(\hat{s}_{t+H},c_{t+H}).
\]

其中 \(V_\psi\) 估计从推演终点继续演化的长期结果，\(c\) 是影响未来结果的上下文。该接口既可供 MCTS、MPC 或其他有限视界决策器使用，也可直接用于长期预测；MCTS 搜索值对齐只是其中一种训练目标。

流行病 TVA 必须显式包含所有会改变终端长期结果的变量：SEIHR 存量、时间位置、上一周感染与住院峰值、干预状态，以及在容量冲击中公开的当前医院容量。容量不能只存在于外部 reward closure 中，否则相同状态在不同容量下会得到相同的终端价值，TVA 无法补偿容量约束变化。预测目标应至少拆分为累计感染、累计超载、峰值住院和动作成本，再按论文奖励组合形成总价值。

当前流行病修订顺序：

1. 先建立独立的长期预测 TVA，用训练期轨迹和 held-out continuation target 验证终端状态到长期指标的映射；预测任务不要求 MCTS。
2. 再将同一 TVA 接入有限视界决策器，先做容量场景的 `rollout + TVA` 与 `rollout-only` 配对；决策器可以是 MCTS，也可以是等价的有限视界搜索，关键是保持相同世界模型、预算和信息合同。
3. TVA 训练目标至少包含长期 continuation target 和多步 TD；若采用 MCTS 对齐，必须记录根节点访问分布、\(Q_H\)、`V_search`、target network 和 stop-gradient。普通 episode-return 回归只能标为 proxy，不能称为 TVA。
4. capacity 验收同时检查总价值、感染、超载、峰值和动作成本；若 TVA 只改善其中一项，应报告价值分解，不以总回报单指标判定机制成败。

此前 `results/iclr_epidemic_capacity_tva_formal_20260912` 及相关 smoke 使用的是无容量上下文的普通 return-value proxy，均标记为失效诊断，不作为 TVA 结论。残差网络仍不是当前 TVA 的必要组件；只有在长期预测误差显示稳定的未建模动力学残差后，才另行评估残差补偿。

## 7. 当前推进方案与范围收束（2026-09-12）

### 7.1 第一原则

本实验的唯一目标是支持论文关于结构化世界模型的样本效率、可靠性、分布外适应和可解释性主张，不承担彻底研究流行病控制或 Beer Game 决策问题本身的任务。若某项细节对上述主张的支撑没有明显影响，不再为其追加实验或长期纠缠。

### 7.2 对既有要求的效力说明

本节优先于本文前文中与当前资源和证据目标不相称的执行要求。以下内容暂不作为推进阻塞条件：完整覆盖所有预算与所有实验臂、完整视界/叶值矩阵、所有外部决策器的统一比较、报告观测的全面性能研究，以及 Beer Game T2–T5 的完整拓扑扩展。相关设计保留为可选后续工作，不得阻止论文主张所需证据的收束。

冻结 OOD 的无效旧协议结果仍明确排除；报告观测的信息泄露仍必须修复，因为它会直接损害对照有效性。闭环比较只需先统一会改变主张解释的关键口径，再据现有结果判断结构模型是否提供可报告的增益或负结果。

### 7.3 当前执行顺序

1. **收束基础证据**：整理稳定环境多种子结果、机制辨识结果、G1 可靠性结果和已完成的冻结 OOD 结果，统一报告效应量、区间及适用边界。
2. **完成最小必要闭环核验**：统一 A2、A1′、A4、A5 的关键评估口径；若结果仍不支持 H1/H4，直接作为结构模型当前闭环收益不足的负结果收束，不继续调参追求排序优势。
3. **补齐直接回应审稿质疑的对照**：完成信息等级和先验分层中对论文解释有实质影响的最小批次；仅保留能够区分结构先验、临床先验与黑盒输入优势的比较。
4. **完成报告观测修正版**：仅在修复隐藏状态泄露后运行必要的性能对照；若该变体不影响主文主张，则作为补充限制性证据，不扩展为完整观测模型研究。
5. **形成论文证据表**：将已完成的正结果、负结果、协议限制和未执行项目统一映射到 G1–G4/H1–H4，完成后停止为补充实验增加与主张无关的扩展。

### 7.4 Beer Game 拓扑扩展

Beer Game 拓扑扩展继续保留，但当前只推进对“结构先验可迁移性”有直接证据价值的最小闭环：先完成 T1 图通用实现与既有结果复现门槛；若 T1 复现通过，再选择一个能直接检验拓扑迁移的代表性变体。T2–T5 全覆盖、规模曲线和运筹决策细节研究暂缓，不作为当前论文主张收束的前置条件。

### 7.5 科学性、主张支撑与洞见的平衡标准

范围收束不等于只追求“跑通”和“显著优于基线”。每个保留阶段必须同时回答三个问题：结果是否直接检验某项论文主张，比较是否具有足够的科学有效性，结果能否说明增益或失败通过何种机制产生。为此：

- 每个阶段至少保留一个公平对照、一个机制指标和一个不确定性报告；不满足时只能作为工程验证，不能写成主张证据。
- 机制指标优先从已有日志提取（辨识误差、守恒/边界违反、动作覆盖、OOD 误差、干预后适应），只有现有结果无法区分关键解释时才新增运行。
- 正结果必须同时报告适用条件；负结果必须说明是结构先验不足、数据覆盖不足、规划协议限制还是任务本身不适配，避免把单一回报差异过度外推。
- 若一个补充实验只增加任务细节而不改变主张判断或机制解释，则停止扩展；若一个小规模对照能够改变主张解释，则优先于大规模重复。

据此，当前方案在“论文主张支撑”上已足够收束，在“科学研究”上保留了公平对照、机制指标和不确定性要求，在“有价值洞见”上将重点放在结构先验何时有效、何时因辨识或规划协议失效，以及 OOD/拓扑变化下失效边界，而不追求完整解决流行病或 Beer Game 决策问题。

### 7.7 SD 内部学习策略与 OOD 机制解释

A2 与 A5 均属于 SD 方法内部的学习策略消融：A2 采用在线辨识并持续规划，A5 采用随机数据进行一次性或周期性被动辨识后规划。A2 未显著优于 A5 不构成 SD 方法的负结果，而是说明在当前任务和预算下，主动在线辨识的额外收益尚未超过被动数据覆盖。后续解释应关注动作覆盖、辨识误差、重拟合时机和 OOD 后参数更新，而不是把 A2/A5 排名作为主张成败标准。

三类 OOD 结果应作为互补机制证据分析：

- **beta 变化**：A2 相对 A1′ 的优势保持，随幅度没有明显扩大，提示结构模型在参数变化下具有稳定性，但参数漂移本身未自动产生额外结构收益。
- **escape 变化**：A2 相对 A1′ 的优势显著扩大，提示当干预改变有效传播结构、而黑盒模型缺乏可解释编辑通道时，结构表示的可编辑性和约束传播可能发挥更大作用。
- **capacity 冲击**：A2 仍优于 A1′，但优势收窄，提示公开的容量约束冲击主要考验约束适应和规划代价权衡，结构模型的可靠性优势仍在，但不必然转化为更大的回报差。

上述解释属于待写入论文的机制性分析，不要求追加覆盖所有 OOD 强度；只需从现有日志核对参数误差、约束违反、动作分布和冲击后适应指标，确认三种模式与机制指标方向一致。若方向一致，即可将 OOD 结果表述为“优势保持、优势扩大和优势收窄”三种互补证据，而非追求单一的 OOD 排名结论。

### 7.9 搜索对齐 TVA 的当前进展（2026-09-12）
已完成搜索对齐终端价值网络的训练烟雾测试：以 A2 的有限深度 MCTS 根节点访问策略加权 Q 值作为监督目标，显式区分 nominal 与 capacity-half 上下文；52 个样本，训练 MAE 约 0.38，目标标准差约 14.57，策略覆盖完整。该目标不使用真实长期回报或特权 oracle，符合 TVA 的定义。

随后进行 capacity OOD 小规模接入验证（seeds 8、9，16 simulations）。运行已生成完整轨迹，但尚未形成正式统计汇总；初步观察 A2 在 capacity-half 下的回报约为 −74.93、−72.84（对应两个种子），不能与正式 64-simulation 结果直接比较。该结果仅作为接口和语义检查，不据此改变论文结论。下一步应在统一 simulation 配置下完成正式 10-seed 搜索对齐 TVA，并与纯 rollout、预测 TVA 使用配对 bootstrap 比较；若未显示稳定增益，则保留“终端补偿可学习但决策收益依赖搜索目标与规划配置”的机制结论。

### 7.10 搜索对齐 TVA 正式结果（2026-09-12）
统一 64 次模拟、10-seed capacity OOD 已完成。capacity-half 冲击后平均回报：A1′ −56.29，A2（搜索对齐 TVA）−62.51，A5 fixed −58.57，A5 receding −57.90。A2 相对 A1′ 下降约 6.23，表明当前搜索对齐终端价值网络尚未改善容量冲击下的决策回报，且引入了新的规划偏差。该结果不否定 TVA 的终端补偿定义，但说明以 nominal/half-capacity 少量状态训练的根节点 Q 目标不足以支持跨冲击决策；容量 OOD 的主结论仍是模型可靠性保持而长期规划转换不足。后续不再扩大该网络调参，仅保留其作为机制边界证据。

### 7.11 容量因果链审计（2026-09-12）
代码审计确认：SEIHR 结构模型的状态转移方程仅由 S、E、I、H、R、干预动作及传播/临床参数决定；`hospital_capacity` 不进入 `daily_kernel` 或 `forward` 的状态转移，因此容量变化不会改变模型预测的感染、住院流量或状态演化。容量仅在 `predict_reward` 中用于计算 overflow 惩罚，并在环境层改变奖励；容量冲击虽可作为公开上下文传给部分价值网络，但没有形成“容量→可治疗/溢出后动力学→未来状态”的结构因果关系。

因此，capacity OOD 下“结构模型可靠性保持但决策收益优势消失”的归因需要修正：问题首先不是 TVA 不足，而是当前 SD 模型没有表示容量影响的动力学因果机制。它可以正确外推容量不变条件下的疫情演化，再由奖励函数评估不同容量下的即时溢出代价，却无法推演容量受限后可能改变的临床转归、有效恢复率或后续传播路径。容量实验对论文主张的有效结论应限定为：在容量仅影响评价成本的设定下，A2 的结构预测优势不自动转化为容量冲击下的规划收益；若要研究容量改变动力学的 OOD，必须先扩展 SD 结构并重新进行识别与验证。本轮不追加该扩展，以免超出支持论文主张所需范围。

### H2 批次协议纠正

### 8.2 供需压力归一化规则

用户意见为”保持 O_max=16 只缩放产能，若足以支撑主张则不复杂化”。审计结论：**该方案不足**。源节点产量为 `min(order, capacity)` 而 `order ≤ O_max`，产能已高于 16，缩放产能不改变任何行为；T3 源节点需 32 吞吐、T5 的 w4/w5 中间节点需 24/32 吞吐，瓶颈是 `O_max` 而非产能。

采用最简单的 T1 不变规则：以节点 v 在高需求期按等比拆单路由的下游总需求 `D_v` 为尺度，所有节点量取 T1 的比例：

| 量 | T1 取值 | 规则 |
|---|---|---|
| `O_max_v` | 16 = 2·8 | `2·D_v`，订货网格仍为 9 级 |
| `cap_v`（源） | 20 = 2.5·8 | `2.5·D_v` |
| `I0_v` | 12 = 1.5·8 | `1.5·D_v` |
| 边初始管道 | 4 = 0.5·8 | `0.5·F_e`，`F_e` 为该边高需求期流量 |
| 零售需求 | 4→8 | 不变 |
| `h, p` | 0.5, 1.0 | 不变（单位成本） |

在 T1 上该规则复现原参数，故 T1 结果与规则前完全一致。每个节点的相对压力 `D_v/O_max_v = 0.5` 与网格分辨率 `D_v/4` 在所有拓扑上相同。该规则由 YAML 加载器自动计算，YAML 不再手写 `capacity`/`O_max`；产能压力变化不作为独立条件，仅通过 §8.6 的 capacity_shock 干预检验。回报同时报告绝对值与按总需求归一化值。

### 8.3 统一模型族与决策协议

- **模型**：T1–T5 全部使用通用 `GenericGraphBeerGameSDModel`（修复 STE 步时门控、接入节点特定参数、按节点索引订货量）。门槛 G-BT2′：通用模型在 T1 上与 `BeerGameSDModel` 前向一致（atol 1e-5，全部 81 联合动作与随机状态）。串行专用类仅保留给历史入口。
- **动作**：全部拓扑采用逐节点顺序子步、`Discrete(9)`、周期感知折扣。T1 同样按该协议运行作为同协议对照；论文 81 联合动作的历史 Table 1/2 作为参照汇总，不重跑（G-BT3 决议）。
- **搜索预算**：每子步 100 次模拟（原定 64 次在渐进拓宽 `|children| < √N` 下无法展开全部 9 个根动作，G-BT6 实测最少 7/9；100 次通过），每周期模型调用数 = 100·|V|（T1 400、T4 1000），同时报告决策数与周期数。门槛 G-BT6：该预算下根节点 9 个动作全部展开。
- **叶值**：主设置为价值网络（episode-return 回归，与论文 Beer Game 入口一致；按本文 TVA 语义审计，不称为 TVA）；消融为纯 rollout，深度 4 周期 = τ+L。
- **RNG**：MCTS 以 (seed, period, substep) 播种；SD 与 BB 臂共享同一随机流，配对单位为训练种子。
- **奖励**：规划奖励由环境布局派生的单一函数生成，训练前断言 36 步随机轨迹上规划奖励 == 环境奖励（G-BT4）。
- **先验初始化**：SD 臂沿用论文 `prior_belief` 扰动（步时 ±3 周期、高需求 ×[0.7,1.3]）；节点特定设定对每个零售节点独立扰动。
- **辨识**：在线，从回放缓冲以 lr 1e-2 更新需求参数，与论文入口一致。
- **评估**：完整 36 周期，10 个评估 episode，与训练分离的评估种子。

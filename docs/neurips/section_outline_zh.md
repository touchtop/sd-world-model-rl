§3 问题设定 (Problem Formulation) [0.75页]
================================================================================

3.1 结构化MDP定义
    - 状态空间 S = Stock变量 (库存、疲劳、队列)
    - 动作空间 A = Flow控制 (订货量、任务分配)
    - 因果图 G = (Stocks, Flows, 延迟)

3.2 结构-参数分离假设
    - A1: 因果结构已知（边已知，参数未知）
    - A2: Stock-Flow守恒律成立
    - A3: 存在有界模型失配（motivate残差学习）

3.3 目标
    - 无限视野折扣回报最大化
    - 满足物理约束（非负库存等）

§5 理论分析 (Theoretical Analysis) [1页]
================================================================================

5.1 核心洞见（直觉先行）
    - 结构约束 → 假设空间缩小 → 采样复杂度降低
    - 因果收缩 → 误差有界传播 → 有效视野缩减

5.2 主要定理
    ┌─────────────────────────────────────────────────────────────────────┐
    │ Theorem 1 (PUCT一致性)                                              │
    │ 在SD先验下，PUCT收敛至最优值，收敛速率O(1/√N)                        │
    ├─────────────────────────────────────────────────────────────────────┤
    │ Theorem 2 (模型失配鲁棒性)                                          │
    │ 模型误差ε_m下，策略次优性 ≤ 2H·ε_m + 规划误差                       │
    ├─────────────────────────────────────────────────────────────────────┤
    │ Theorem 3 (视野缩减) ⭐核心理论贡献                                  │
    │ 若因果收缩系数κ<1，有效规划深度 H_eff = O(log(1/ε)/log(1/κ))        │
    │ → 浅搜索+终端价值 ≈ 深搜索                                          │
    └─────────────────────────────────────────────────────────────────────┘

5.3 与Tabula Rasa方法对比
    - SD-MCTS: O(d) 采样复杂度，d为参数数量
    - DreamerV3: O(|S||A|) 采样复杂度

# XSokoban first 第 2 关 Room-GFT A21 stand-lock guard 诊断

## 核心结论

A21 继承 A20，增加不可释放 critical stand blocker 诊断与根保护，用于避免调度依赖已在目标/角落中的箱子作为后续站位格。
A20 对照为 `max_steps`，执行 `80` 个 push 后 `boxes_on_goals=2`；A21 smoke 为 `max_steps`，执行 `80` 个 push、`77` 个闭环决策后 `boxes_on_goals=0`。
A20/A21 首个决策差异为 `3`；A21 locked stand selected 为 `73`，assigned-goal selected 为 `0`。
本次 A21 是负结果：stand-lock 风险信号是真实的，但只在根选择和 leaf 中惩罚不可释放站位阻塞，会过早偏离 A20 的有效装填前缀；该版本没有生成新的 release action，因此不能修复两个目标后的释放缺口。

## 方法含义

A21 检验的是：A20 后半段的失败是否来自不可释放 stand-lock。若该 guard 降低目标数或提前失败，则说明仅禁止 stand-lock 还需要配套可执行 release 生成。

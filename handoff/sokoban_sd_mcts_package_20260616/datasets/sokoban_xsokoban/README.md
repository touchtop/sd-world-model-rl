# XSokoban first-40 evaluation set

This directory stores the first 40 classic XSokoban screens converted to the local Boxoban-style `; id` text format.

Source: https://github.com/andrewcmyers/xsokoban, directory `screens/`, files `screen.1` through `screen.40`.
The source repository is a public mirror of the classic X11 XSokoban game resources.

Rationale: Taufeeque et al. report an `Xsokoban` collection with `# = 40` and examples named `XSokoban level 30/31`; this file follows that first-40 screen convention.

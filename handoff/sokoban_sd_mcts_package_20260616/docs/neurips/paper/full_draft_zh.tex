\large 面向高效采样规划的结构化世界模型}
\author{}
\renewcommand{\abstractname}{摘要 (Abstract)}
\date{}

\begin{document}

\maketitle
\begin{abstract}

现代基于模型强化学习（Model-Based Reinforcement Learning, MBRL）依赖大规模神经网络近似隐状态转移，在复杂决策任务中取得显著进展。然而，这类无结构先验的端到端学习范式对海量交互数据高度依赖，且由于缺乏底层物理与守恒律约束，常在多步展开时出现误差累积与物理一致性破坏，面对分布外（OOD）扰动亦表现出明显退化。

在供应链与物理控制等安全性和长期稳定性要求突出的场景中，系统往往具有已知的宏观拓扑、守恒关系或解析动力学，但现有通用 MBRL 难以有效注入并利用此类结构先验。为此，我们提出 \textbf{SD-MCTS (System Dynamics Monte Carlo Tree Search)}。该框架以结构化世界模型刻画环境动力学，将学习重点压缩到少量未知参数的系统辨识，并结合离线训练的终端价值网络，对有限规划视界下的截断误差进行补偿；同时，显式结构表示也使模型能够在测试时直接响应已知干预。

\revdel{在包含延时反馈与 OOD 扰动的评测任务中，我们在 Beer Game 上观察到显著的样本效率优势，并在公开基准 DMControl Cartpole-Swingup 上表明，该框架在较低真实交互预算下仍能取得有竞争力的控制结果。进一步地，通过对搜索树内部轨迹一致性与多步误差传播的分析，我们说明了结构约束如何转化为更稳定的规划表现。最后，在干预可观测且可映射到结构方程修改的前提下，我们在 Beer Game 的两类 OOD 结构干预设置中展示了无需重新训练神经网络的零样本（Zero-Shot）适应能力。}
\revadd{在包含延时反馈与 OOD 扰动的评测任务中，我们在 Beer Game 上观察到显著的样本效率优势，并在公开基准 DMControl Cartpole-Swingup 上表明，该框架在较低真实交互预算下仍能取得有竞争力的控制结果。进一步地，在更高难度公开基准 Hopper-Hop 上，结构化扩展仅用 \(50\text{k}\) 步真实环境交互，已取得高于公开 \(100\text{k}\) 基线的平均回报。接着，通过对搜索树内部轨迹一致性与多步误差传播的分析，我们说明了结构约束如何转化
为更稳定的规划表现。最后，在干预可观测且可映射到结构方程修改的前提下，我们在 Beer Game 的两类 OOD 结构干预设置中展示了无需重新训练神经网络的零样本（Zero-Shot）适应能力。}
\end{abstract}

\hypertarget{sec-introduction}{%
\section{1. 引言 (Introduction)}\label{sec-introduction}}

\begin{quote}
\emph{``既然多数复杂系统运行在已被科学界长年提炼的物理法则之上，为何要求智能体在缺乏结构先验的条件下于隐空间学习这些守恒规律？''}
\end{quote}

在处理高度复杂的序列规划（Sequential Decision-Making）任务时，基于模型的强化学习（MBRL）框架近年来凭借对环境动力学的建模能力成为研究焦点。主流方法（如 Dreamer 系列与 TD-MPC2）倾向于在隐空间中采用 MLP、RNN 或大规模 Attention 结构作为高维环境特征的连续推演器（World Model）。这种通用函数逼近的``白板学习（Tabula Rasa）''理念依赖超大参数量与自回归损失，在视觉密集、规则同质的模拟环境中展现了较强的经验泛化能力。

然而，当该机制迁移到容错要求极高的现实高风险序列决策任务（如物流供应链调度、长期设备老化控制、流行病学干预）时，其结构性缺陷逐渐显露：第一，\textbf{样本效率不足 (Data Inefficiency)}。真实场景交互成本高昂，在仅有约 \(\approx 10^3 \sim 10^4\) 级样本预算下，缺乏归纳偏置的隐空间模型很难从噪声中稳定抽取满足守恒约束的状态转移机制。第二，\textbf{缺乏不变量约束导致的外推阶段的约束违反 (Violations in Extrapolation)}。现有通用 MBRL 的转移核未显式嵌入守恒限制，在超出视界截断后进行多步展开时，易遭遇非线性映射带来的特征误差发散，从而引发``非物理的产出增加''或``状态违反非负约束''等物理不一致。尤其关键的是，动作掩码（action masking）等事后规避措施只能限制动作可行性，并不保证 MCTS 搜索树内部轨迹的物理一致性，因此仍会引入系统性规划偏差。第三，\textbf{对因果干预的脆弱性 (Vulnerability to Causal Interventions)}。当系统出现分布外突变（如生产力骤减或拓扑链路断裂）时，全连接模型由于规则与参数的黑盒耦合，往往缺乏零样本干预适应能力。

事实上，在多数科学计算与工业控制系统中，系统底层事件的逻辑图谱（如流量沿上游至下游传导、传染满足接触动态率等结构不变量）并非完全未知。本文将结构先验（Structural Priors）形式化为：已知系统拓扑 \(\mathcal{T}\)、在该拓扑上定义的动力学算子 \(f_{\mathcal{T}}\)，以及由守恒与可行性约束刻画的可行集 \(\mathcal{C}\)。真正缺失的通常是局部的标量效率或时变残差（例如未观测的老化敏感系数）。若因这些局部参数的不确定而放弃已知的系统级因果拓扑全局结构（Causal Graph Structure / Structural Priors），转而让通用神经逼近器重新学习系统动力学方程，不仅降低样本利用率，还会削弱预测过程的稳定性。

针对上述挑战，本文提出 \textbf{系统动力学与蒙特卡洛树搜索融合控制框架（SD-MCTS）}。其中，本文所称“系统动力学（System Dynamics, SD）”特指 Forrester~(1961) 与 Sterman~(1989) 的存量-流量-反馈（stock-flow-feedback）建模范式，而非一般无结构的黑盒动力系统拟合。该方法强调先验结构与深度神经功能的解耦，避免纯黑盒的无约束函数映射。为应对长视野延迟反馈与分布外异变，我们将方案组织为三个核心模块：

\begin{enumerate}
\item \textbf{系统动力学结构模型 (System Dynamics Structural Model)}：以 stock-flow-feedback 白盒系统动力图及其流量守恒约束构建生成核，仅用少量数据估计其中低维未知参数，从而抑制多步前推中的雅可比放大效应。
\item \textbf{基于局部图遍历的蒙特卡洛树搜索 (Constraints-Bound MCTS)}：在线规划时，搜索仅在满足质量守恒等先验约束的图拓扑边界内展开。
\item \textbf{离线终端价值对齐 (Terminal Value Alignment)}：随着搜索深度的增加，MCTS 往往面临动作空间组合复杂度呈指数增长的挑战，因此我们在较短的深度 \(H\) 处截断叶节点，并引入异步离线训练的近似价值 \(V_{\psi}\) 进行势能补偿，以较低的在线计算开销获得相当于长视野的规划收益。
\end{enumerate}

本研究的主要贡献如下：

\begin{enumerate}
\item \revdel{\textbf{结构先验驱动的样本效率提升}：在涵盖离散延迟（Beer Game）与连续欠驱动物理控制（Cartpole-Swingup）的复杂环境中，SD-MCTS 在仅拥有极低交互预算时即可取得有竞争力的性能；其中，在未经修改的公开基准 DMControl Cartpole-Swingup 上，我们采用共享先验 + 按种子微调（shared prior + per-seed finetune）的协议，在一次“35,000 步共享先验预训练 + 5,000 步目标种子微调”的统一口径下获得 802.9 的三种子聚合均值，且无单个种子低于 700。结合流形非负截断、系统图守恒算子与共享先验初始化，该框架在保持可解释性的同时有效遏制了树搜索内部的物理失真、敏感状态附近的策略漂移以及跨种子性能塌缩。}\revadd{\textbf{结构先验驱动的样本效率提升}：在涵盖离散延迟（Beer Game）、连续欠驱动物理控制（Cartpole-Swingup）以及更高难度公开运动控制基准（Hopper-Hop）的环境中，结构化方法在极低交互预算下均取得了有竞争力的性能；其中，在未经修改的公开基准 DMControl Cartpole-Swingup 上，我们采用共享先验 + 按种子微调（shared prior + per-seed finetune）的协议，在一次“35,000 步共享先验预训练 + 5,000 步目标种子微调”的统一口径下获得 802.9 的三种子聚合均值，且无单个种子低于 700；在更高难度的 Hopper-Hop 上，结构化扩展仅用 \(50\text{k}\) 步真实环境交互，已取得高于公开 \(100\text{k}\) 基线的平均回报。结合流形非负截断、系统图守恒算子、共享先验初始化等设计，该框架在保持可解释性的同时有效遏制了树搜索内部的物理失真、敏感状态附近的策略漂移以及跨种子性能塌缩。}
\item \textbf{多步预测泛化的误差上界收敛与规划视界缩减}：我们从理论上证明，将转移矩阵限制在不变包络集内可将多步自回归误差上界压缩至常量阶 \(\mathcal{O}(1)\)。在此基础上，终端价值补偿能够缓解有限视界截断带来的性能损失，为以较浅规划深度实现稳定决策提供理论依据。
\item \textbf{基于可编辑因果图的强干预鲁棒性}：为对齐真实 OOD 环境演变，我们在预训练世界模型上引入基于结构方程局部修改的拓扑干预 \(f \leftarrow g(f, \iota_t)\)。在此类强干预设置下，依托白盒守恒结构的响应性，SD-MCTS 能显著抑制纯神经映射的失真与跨种子方差，为无需重新训练条件下的在线突变适应提供可行范式。
\end{enumerate}

\hypertarget{sec-related-work}{%
\section{2 相关工作 (Related
Work)}\label{sec-related-work}}

SD-MCTS
融合了基于模型的强化学习（MBRL）、物理启发式机器学习以及经典运筹学的滚动优化控制思想。我们将本研究置于以下研究脉络中进行定位：

\textbf{基于模型的强化学习 (Model-Based Reinforcement Learning)}
近年来，MBRL 在样本效率和长时域规划上取得了广泛关注。Dreamer
系列将环境的动态映射压缩到隐空间（Latent
Space）内通过自回归循环网络（RSSM）进行端到端学习，而 MuZero 与 TD-MPC
则同样摒弃先验直接在潜空间内展开蒙特卡洛树或滚动视界评估。尽管在游戏或纯视觉模拟环境中取得了有竞争力的性能，但这类纯数据驱动的“从零先验学习”模型在泛化时缺乏物理一致性约束。相比之下，SD-MCTS
摒弃了从极高维权重中内隐地学习动态方程，它要求预设环境的结构化逻辑，转而在较低样本复杂度下对低维环境流形残差进行基于结构先验的残差校正。

\textbf{物理启发式深度学习 (Physics-Informed Machine Learning)}
将先验结构注入神经网络在科学计算中已被证明极为有效。Physics-Informed
Neural Networks (PINNs) 通过将偏微分方程引入损失函数实现软约束，Neural
ODEs 与 Hamiltonian Networks
则将能量守恒硬编码进入模型的导层推演中。SD-MCTS
在方法论上与之相近：以硬约束保持结构的物理不变量，同时利用梯度下降搜寻局部未知系数。然而，我们的重点不仅在于完成系统辨识（System
Identification），而是将其与树搜索和近似动态规划紧密耦合，进而实现从建模到控制的一体化框架。

\textbf{带终端代价的滚动优化 (Rolling Horizon Optimization with Terminal
Costs)}
模型预测控制（MPC）在工业决策中被广泛应用，但面对系统延迟时效长远的场景，受限的探索深度
\(H\) 必然引发有限视界导致的短视偏差（Truncation
Bias）。近似动态规划（ADP）通过值函数（Value
Function）估计尾部回报以代偿短视。SD-MCTS
是这一机制在含参推断下的参数化函数逼近扩展：离线拟合的神经网络参数化的终端价值近似器 \(V_{\psi}\) 本质上扮演了非线性且高维的自适应终端代价估计，赋予了有限深度的
MCTS 逼近无穷视界的最优性。

\hypertarget{sec-problem-setup}{%
\section{3 问题定义 (Problem
Setup)}\label{sec-problem-setup}}

我们将具有物理不变量约束的动态决策问题建模为一个带结构的离散时间马尔可夫决策过程
(Structured MDP)
\(\mathcal{M}=\langle \mathcal{S},\mathcal{A},\mathcal{P},\mathcal{R},\gamma\rangle\)，其中
\(\gamma\in(0,1)\)。物理可行域记为 \(\mathcal{C}\subseteq\mathcal{S}\)，并通过投影算子 \(\Pi_{\mathcal{C}}\) 表示约束满足。默认观测为全状态 \(s_t\)；若为部分可观测情形，则以观测 \(o_t\) 作为策略输入。在时刻 \(t\)，智能体根据策略 \(\pi(a_t\mid s_t)\)
选择动作 \(a_t\)，获得奖励 \(r_t=\mathcal{R}(s_t,a_t)\)，并由环境转移核
\(\mathcal{P}(s_{t+1}\mid s_t,a_t)\) 生成下一状态。目标是求解： \[
J(\pi)=\mathbb{E}_{\tau\sim(\pi,\mathcal{P})}\!\left[\sum_{t=0}^{\infty}\gamma^t r_t\right]
\] 其中 \(\tau=(s_0,a_0,s_1,\ldots)\) 为由 \((\pi,\mathcal{P})\)
诱导的轨迹分布。

与标准无结构 RL 不同，本文关注具有已知物理交互结构但未知动力学参数的系统。本文中的 System Dynamics（SD）采用 Forrester 式抽象：状态对应库存（stock），转移由流量（flow）守恒与反馈回路共同决定。为此，我们在转移建模上引入如下结构化设定：

\textbf{假设 1：结构--参数分离 (Structure--Parameter Separation)}
真实环境可写为 \( s_{t+1}=f(s_t,a_t;\theta^\star)+\xi_t \)，其中 \(f\)
的解析形式（如守恒关系、非负流约束、网络拓扑耦合）是已知的，未知成分仅为参数
\(\theta^\star\in\Theta\subset\mathbb{R}^d\)。噪声项 \(\xi_t\)
描述未建模扰动与随机性，满足 \(\mathbb{E}[\xi_t\mid s_t,a_t]=0\) 且
\(\mathbb{E}\!\left[\|\xi_t\|^2\mid s_t,a_t\right]\le \sigma^2\)。此外，\(f\)
对 \(\theta\) 可微，并对 \((s,a)\) 局部
Lipschitz，以支持基于梯度的参数辨识与策略优化。约束投影 \(\Pi_{\mathcal{C}}\) 假设为非扩张算子（例如闭凸集 \(\mathcal{C}\) 上的欧氏投影），即 \(\|\Pi_{\mathcal{C}}(x)-\Pi_{\mathcal{C}}(y)\|\le \|x-y\|\)。

\textbf{假设 2：低维隐流形与均值场近似 (Low-Dimensional Manifold \&
Mean-Field Approximation)}
尽管状态与动作可能高维，决定系统演化的有效参数往往位于极低维流形，即
\(d=\dim(\theta^\star)\ll \dim(\mathcal{S})+\dim(\mathcal{A})\)。同时，为获得可稳定反向传播的长时域前向展开（rollout），我们以条件期望动力学作为优化代理：\(\bar f(s_t,a_t;\theta)\triangleq \mathbb{E}[s_{t+1}\mid s_t,a_t;\theta]\)，并在训练中采用均值场近似
\(s_{t+1}\approx \bar f(s_t,a_t;\theta)\)，将高频、离散的外源扰动留在残差项中处理。该近似保留了主导性的系统演化趋势，同时显著降低了梯度估计方差，提高了学习残差动力学的稳定性（但当高方差、离散外源冲击占主导时，该均值场近似可能失效并低估尾部风险）。

在上述设定下，问题可分解为：在已知结构约束下辨识 \(\theta^\star\)，并在由
\(f(\cdot,\cdot;\theta)\)
参数化的转移族上学习高回报策略。该分解不仅为我们在第 5
节的样本复杂度界分析提供了理论基础，也使得针对算子实施分布外（OOD）干预具有明确的可解释性与可操作性。我们定义干预协议（Intervention Protocol）为：可观测干预 \(\iota_t\in\mathcal{I}\) 映射为对结构方程的局部修改 \(f \leftarrow g(f,\iota_t)\)，且不进行额外神经网络重训练。

\hypertarget{sec-method}{%
\section{4 方法 (Method)}\label{sec-method}}

沿用第\hyperlink{sec-problem-setup}{3}节的 MDP 定义与结构化设定，本节详述 SD-MCTS 的核心机制。SD-MCTS 摒弃了由神经网络无约束拟合全局转移的黑盒范式，转而由三个紧耦合的模块构成：
(1) \textbf{结构化动力学先验}：用满足物理守恒/可行性约束的可微转移模型替代全连接世界模型；
(2) \textbf{截断树搜索}：在结构化流形内进行深度受限的在线 MCTS 规划；
(3) \textbf{终端价值对齐（Terminal Value Alignment, TVA）}：将价值网络训练目标与 MCTS 叶节点自举（bootstrap）目标对齐，消除规划截断偏差。

\hypertarget{sub-overview}{%
\subsection{4.1 整体框架}\label{sub-overview}}

\includegraphics[width=\textwidth]{fig_architecture.pdf}
\emph{图 1: SD-MCTS 整体架构图。由左至右包含四大核心机制：(A) \textbf{结构化世界模型}利用物理投影算子 $\Pi_{\mathcal C}$ 保障转移可行性，避免黑盒误差；(B) \textbf{结构约束 MCTS}（Structure-Constrained MCTS）在先验物理模型上开展深度受限（最大深度 $H$）的树搜索规划，利用价值网络 $V_\psi$ 进行叶节点自举；(C) \textbf{终端价值对齐（TVA）}驱动评价函数更新，将 MCTS 的搜索估计值 $\hat{V}_{\text{search}}$ 转化为软目标直接对齐 $V_\psi$；(D) 基于显式物理拓扑，系统支持测试时\textbf{零样本干预}（例如直接阻断图网络边连接），无需任何模型重训。}

在每个决策时刻 $t$，给定真实状态 $s_t$，智能体的执行闭环如下：首先执行 $n$ 次在 $\hat{\mathcal P}_\theta$ 上的 MCTS 模拟（最大深度 $H$），并使用神经网络 $V_\psi$ 评估叶节点势能；随后根据根节点动作访问统计量执行动作 $a_t$；最后将真实转移 $(s_t,a_t,r_t,s_{t+1})$ 存入回放池 $\mathcal D$，并每 $K$ 步异步更新模型参数 $\theta$ 与价值网络 $\psi$。

该设计的核心在于：\textbf{在线规划和离线价值学习共享同一个终端语义}。MCTS 在叶节点依赖 $V_\psi$ 提供长期视界的代偿，而 $V_\psi$ 又被显式训练以拟合 MCTS 产生的截断回报目标（详见 4.4 节），从而形成互相强化的闭环。

\hypertarget{sub-structured-model}{%
\subsection{4.2 结构化可微世界模型 (Differentiable Structural World Model)}\label{sub-structured-model}}

与依赖黑盒神经网络直接拟合全局转移的世界模型不同，SD-MCTS 并不让模型从数据中重新学习整个动力学映射，而是先按照系统动力学（SD）的存量--流量--反馈表示设计状态更新骨架，再仅对其中少量未知参数进行辨识。这样做的一个重要目的，是在这类典型问题中有效利用已知的领域知识；与此同时，它也将多步展开中的主要结构关系固定下来，从而在结构层面抑制误差累积与发散。

更具体地说，SD 在这里并不是泛指任意动力系统，而是指一种显式的因果图建模方式：系统中的关键状态量被表示为存量（stocks），节点之间的局部转移、补给、消耗或作用被表示为流量（flows），而反馈回路（feedback loops）则刻画当前状态如何进一步影响后续流量或控制作用。于是，一步状态更新不再被视为一个黑盒函数值，而是由“存量变化 = 流入 - 流出 + 局部作用”这一类结构化关系组合而成；不同任务之间变化的是具体变量和局部方程，而不是这一建模范式本身。

\textbf{参数化与投影约束.}
我们将环境状态转移刻画为受约束的状态更新过程：
\[
\hat s_{t+1}= \hat{\mathcal P}_\theta(s_t,a_t) = \Pi_{\mathcal C}\!\left(f_{\mathcal T}(s_t,a_t;\theta)\right)
\]
其中，\(\mathcal T\) 表示已知的因果拓扑，\(f_{\mathcal T}\) 表示在该拓扑上由局部方程拼接而成的可微更新算子，\(\theta\) 为待在线估计的低维未知参数，\(\Pi_{\mathcal C}\) 则将更新结果投影回物理可行域 \(\mathcal C\)；这里的可行域通常由非负性、容量边界和守恒关系等约束刻画，当 \(\mathcal C\) 非凸时可采用近似投影 \(\tilde{\Pi}_{\mathcal C}\)。

这一设计的关键在于：模型的自由度只保留在少量具有明确物理意义的参数上，而不再交给一个无结构网络去吸收全部动力学关系。因此，与黑盒潜在动力学相比，\(\hat{\mathcal P}_\theta\) 更容易在低样本条件下完成系统辨识，并在多步前推时保持物理一致性。

\textbf{系统辨识目标.}
整个前向操作图 $\hat{\mathcal P}_\theta$ 完全由基础张量算子构建，几乎处处可微。世界模型的学习由此化简为基于回放数据的重构优化：
\[
\mathcal L_{\text{model}}(\theta)= \mathbb E_{(s_t,a_t,s_{t+1})\sim\mathcal D} \left[ \left\| s_{t+1}- \hat{\mathcal P}_\theta(s_t,a_t)\right\|_2^2 \right]
\]
这种显式结构约束为后文在约束多步联合展开下推导常数级 $O(1)$ 误差上界提供了关键条件。

\hypertarget{sub-mcts}{%
\subsection{4.3 基于结构先验的截断 MCTS (Structure-Constrained MCTS)}\label{sub-mcts}}

对给定环境特征 $s_t$，SD-MCTS 在 $\hat{\mathcal P}_\theta$ 上执行在线搜索。单次迭代包含节点选择、扩展与模拟、以及叶节点自举与回传：

\textbf{节点选择 (Selection).}
在搜索树内部，状态通过 \(\Pi_{\mathcal C}\) 保持可行，并在可行动作集合 \(\mathcal A(s)\) 上按照置信区间上界（UCB）法则沿树下降以平衡探索与利用（Exploitation）：
\[
a^\star = \arg\max_a \left[ Q(s,a) + c_{\text{ucb}} \sqrt{\frac{\log(N(s)+1)}{N(s,a)+1}} \right]
\]
其中 $N(s,a)$ 为动作访问次数，$c_{\text{ucb}}$ 为调节探索强度的常数。

\textbf{扩展与模拟 (Expansion and Rollout).}
对于未扩展叶节点，系统使用 $\hat{\mathcal P}_\theta$ 及相应的可行域约束前向模拟至最大搜索深度 $H$，由此获得符合物理约束的模拟轨迹，提取预测奖励序列 $\hat{r}_{t:t+d-1}$ 以及深度为 $d$ 的叶节点状态 $\hat{s}_{t+d}$。

\textbf{叶节点自举与回传 (Leaf Bootstrap and Backup).}
该遍历路径的回报估计 $\hat{G}_H$ 结合了展开阶段的累计折扣回报及基于价值网络 $V_\psi$ 的长期价值估计（自举项）：
\[
\hat G_H = \sum_{k=0}^{d-1}\gamma^k \hat r_{t+k} +\gamma^d V_\psi(\hat s_{t+d})
\]
搜集完毕后，使用标量 $\hat{G}_H$ 沿历史路径反向回传（backup），更新沿途节点的访问计数与 $Q$ 价值估计。一旦达到搜索预算上限，在真实环境中执行的真实动作将从根节点访问次数最多的动作中选出（即通常测试时的 $\arg\max_a N(s_t,a)$）。

\hypertarget{sub-tva}{%
\subsection{4.4 终端价值对齐 (Terminal Value Alignment)}\label{sub-tva}}

长周期任务中过度依赖纯 MCTS 会受指数级计算复杂度限制（即 $\mathcal{O}(|\mathcal{A}|^H)$ 计算瓶颈）。仅凭传统的单步时序差分（1-Step TD）驱动价值评估器亦经常提供缺乏长时程信息的短期偏置价值估计。借鉴近期策略优化与规划方法，我们提出 TVA，将价值网络目标对齐到由 MCTS 搜索树统计构造的价值目标中。

在每次与系统交互时，根据树搜索得到的访问计数与动作价值统计形成加权目标：
\[
\hat V_{\text{search}}(s_t)= \sum_{a \in \mathcal{A}} \pi_{\text{mcts}}(a|s_t)\,\hat Q_H(s_t,a),
\quad \text{其中}\ \pi_{\text{mcts}}(a|s_t)=\frac{N(s_t,a)^\alpha}{\sum_b N(s_t,b)^\alpha}
\]
上式中 $N(s_t,a)$ 为访问次数，$\alpha$ 为温度系数，$\hat Q_H(s_t,a)$ 为根节点动作价值并融合了局部搜索结构信息。在此依托下，异步优化的价值网络 $V_\psi$ 的更新目标可写为加权组合损失函数：
\[
\mathcal L_{\text{val}}(\psi)= \underbrace{ \mathbb E_{s_t\sim\mathcal D} \left[ \left( V_\psi(s_t)-\operatorname{sg}\!\left(\hat V_{\text{search}}(s_t)\right) \right)^2 \right]}_{\text{TVA Alignment Loss}} + \lambda_{\text{td}} \underbrace{ \mathbb E_{\mathcal D} \left[ \left( V_\psi(s_t)-\left(r_t+\gamma \bar V_\psi(s_{t+1})\right) \right)^2 \right]}_{\text{1-step TD Target}}
\]
$\operatorname{sg}(\cdot)$ 作为停止梯度操作（stop-gradient）标识保证训练收敛。这让截断于极浅探索前瞻（如 $H=1$）的短前瞻 MCTS 也能获取并比拟长距决策视野的高质量引导信号。

\hypertarget{sub-inference-prior}{%
\subsection{4.5 共享价值先验与按种子微调 (Shared Value Prior and Per-seed Finetuning)}\label{sub-inference-prior}}

这里所说的共享价值先验与按种子微调，针对的正是第 4.4 节 TVA 中用于叶节点自举的终端价值网络 \(V_\psi\)。换言之，本节讨论的不是一个额外引入的新模块，而是：在低样本、多种子条件下，如何更稳定地学习截断规划所需的终端价值估计。

在低样本条件下，结构化世界模型可以将动力学学习压缩到少量具有物理意义的参数上，但叶节点终端价值估计的稳定性仍然可能成为规划性能的主要瓶颈。尤其在连续控制任务中，如果仅依赖单个随机种子的有限数据训练 \(V_\psi\)，不同运行实例之间往往会因为状态覆盖差异而形成较大的估值方差；这种差异在敏感状态附近会进一步放大，并直接影响 MCTS 的叶节点自举质量与动作选择结果。

为此，我们在 SD-MCTS 中采用\textbf{共享价值先验 + 按种子微调}的训练协议。具体而言，先在一组与论文评测所用种子相分离的开发种子上训练共享价值先验，使 \(V_\psi\) 先学习跨种子相对稳定的终端价值几何；随后再以该先验为初始化，对目标随机种子进行局部微调，以吸收其特有的状态分布与残余动力学差异。前者用于降低低样本条件下的价值估计方差，后者则保留对目标实例的局部适配能力。

这一设计并非试图抹平所有随机种子之间的差异，而是在\textbf{共享稳定先验}与\textbf{保留个体适配}之间取得平衡。对于本文所关注的“结构化动力学 + 截断搜索 + 终端价值补偿”框架而言，这一步尤为关键：一旦 TVA 所训练的 \(V_\psi\) 在不同随机种子之间出现系统性漂移，MCTS 叶节点自举的质量就会直接下降；而通过共享价值先验初始化，再辅以目标种子的少量微调，可以更稳定地支撑搜索阶段的终端价值评估。相关公开基准结果见第 6.5 节。

\hypertarget{sub-zero-shot}{% 
\subsection{4.6 因果图上的显式零样本干预 (Explicit Graph Editing for Zero-Shot Formulation)}\label{sub-zero-shot}}

对于通用 MLP 或注意力组装的黑箱函数近似器，如果在演化过程中发生局部物理属性的结构突变（如灾害截断某物流支线），由于隐含耦合关系（未显式建模的依赖），智能体将会产生严重的分布外泛化误差并要求大量新样本进行参数更新。

SD-MCTS 天然保留着物理拓扑结构表示，这赋予了它精细的局部结构干预能力。我们将干预 $\iota_t \in \mathcal{I}$ 映射为替换算子集合中的局部方程 $f \leftarrow g(f, \iota_t)$，规划仅在该修改后重新运行 MCTS，有效规避了纯神经模型的全局灾难性遗忘。该局部变动会依凭微分图逻辑通过因果传播机制影响至多步未来的代价流。尽管原有学习建立的基础判别势能 $V_\psi$ 会在此刻经历因果模型失配导致的估计偏差，但依托 MCTS 鲁棒的树搜索机制，模型依然可规避不可行或高风险状态区域，在短时尺度上展现出相当的系统鲁棒性与恢复能力。

\hypertarget{ux7406ux8bbaux7ed3ux679c-theoretical-analysis}{%
\section{5 理论结果 (Theoretical
Analysis)}\label{ux7406ux8bbaux7ed3ux679c-theoretical-analysis}}

本节提供了有限样本理论保证（Finite-Sample Guarantees），以解释结构化先验如何在分布偏移下约束估计维度并提升系统泛化鲁棒性。为表述简洁，本节核心结论将主要陈述非正式命题（Informal Propositions）与理论误差界，完整的严格数学分析与证明见补充附录 A.7。

\hypertarget{ux7ed3ux6784ux5316ux63a8ux65adux7684ux6837ux672cux590dux6742ux5ea6-sample-complexity-of-structured-inference}{%
\subsection{5.1 结构化推断的样本复杂度 (Sample Complexity of Structured
Inference)}\label{ux7ed3ux6784ux5316ux63a8ux65adux7684ux6837ux672cux590dux6742ux5ea6-sample-complexity-of-structured-inference}}

在有限样本下，未引入结构先验的离散世界模型需要无约束地估计高维联合转移类，这显著增大了统计复杂度。相比之下，SD-MCTS 利用结构先验将假设类从全状态特征体积约束至极低维的物理参数子空间，从而实现了样本复杂度的数量级削减。

\textbf{命题 1：结构化推断的样本复杂度 (Sample Complexity of Structured Inference). }
假设非线性转移受控于隐含的结构化转移映射（Structural Transition Map）
\(s' = \mathcal{P}(s, a ; \theta^\star) + \xi\)，其中物理参数
\(\theta^\star \in \mathbb{R}^d\)（\(d\) 为有效参数维度），为简化推导，假设智能体能够通过环境模拟器（Environment
Simulator, 充当Generative Oracle）在任意状态进行独立重采样，其转移观测遭遇的附加环境白噪声遵从
\(\sigma\)-次高斯分布 (\(\|\xi\|_{\psi_2} \leq \sigma\))。

在特征变量满足持续激励（Persistent Excitation，即其协方差阵最小特征值满足界限 $\lambda_{\text{min}}(\Sigma) \ge \mu > 0$）的条件下，为以至少 $1-\delta$ 的概率使参数估计误差收敛至 $\|\hat{\theta} - \theta^\star\|_2 \le \epsilon$，所需探索集大小的充分条件为：
\[ N_{\text{SD}} = \mathcal{O}\left( \frac{\sigma^2}{\mu} \frac{d + \log(1/\delta)}{\epsilon^2} \right) \]

相比之下，若对物理系统不作任何先验结构假定（如经典的表格型有限 MDP 转移估计），则所需的样本复杂度至少随 \(|\mathcal{S}||\mathcal{A}|\) 呈线性增长，甚至可达
\(\mathcal{O}\big( \frac{|\mathcal{S}|^2|\mathcal{A}| \log(1/\delta)}{\epsilon^2} \big)\) 级。该命题揭示了基于结构的系统辨识任务的样本需求仅与有效物理维度 \(d\) 呈线性依赖，可直接化归（reduce to）为一个与系统状态空间基数无关的低维标定问题。这预示了后续第 6.2.1 节中评估的 SD-MCTS 极高经验样本效率的理论根源。

\hypertarget{ux6291ux5236-ood-ux6563ux9038ux4eceux6307ux6570ux7ea7ux590dux5408ux8befux5deeux5230ux5b88ux6052ux754cux5ea6-bounding-compounding-errors-via-conservation}{%
\subsection{5.2 正不变约束下的多步预测误差上界 (Multi-step Error Bounds under Positive Invariance)}\label{ux6291ux5236-ood-ux6563ux9038ux4eceux6307ux6570ux7ea7ux590dux5408ux8befux5deeux5230ux5b88ux6052ux754cux5ea6-bounding-compounding-errors-via-conservation}}

在离散时间点进行多步展开是 Model-based
规划器的典型难点。在缺乏物理不变量的自回归生成中，由于单步雅可比（Jacobian）连乘效应，多步累加的误差递推常常呈几何增长（Compounding
Errors）。

\textbf{命题 2：正不变与 Lipschitz 假设下的多步状态误差上界 (Multi-step Error Bounds under Positive Invariance). }
定义多步推演的绝对残差期望为 \( e_t := \mathbb{E}[\|s_t - \hat{s}_t\|] \)，假设单步映射存在固有估计扰动 \(\epsilon_{\text{model}}\)。对于无结构约束的全连接网络
\(f_{\text{MLP}}\)，其全局 Lipschitz 常数通常满足 \(L_f > 1\)，则 \(H\)
步展开误差遵循指数界度：
\[ e_H^{\text{MLP}} \le L_f^H e_0 + \frac{L_f^H - 1}{L_f - 1} \epsilon_{\text{model}} = \mathcal{O}(L_f^H) \]

而在具有正不变集（Positively Invariant Set）性质的结构化动力学系统下，如果状态流形通过守恒流动（Mass
Balance）及非负包络收缩算子（例如库存 \(q \ge 0\) 的投影截断算子
\(\Pi_{\mathcal{C}}\)）严格维持在可行域内，当 \(\mathcal{C}\) 闭凸时，此类投影算子天然具有非扩张性。若受控系统在工作区间内满足局部收缩界限 \(L_f \le 1\)，则系统预测差异随时间的累加可被严格限制在线性增长范围内，并在 \(0 \le L_f < 1\) 时具有常数级上界：
\[
e_H^{\text{SD}} \le 
\begin{cases}
e_0 + H\epsilon_{\text{model}} = \mathcal{O}(H), & L_f = 1 \\
L_f^H e_0 + \frac{1 - L_f^H}{1 - L_f} \epsilon_{\text{model}} \le e_0 + \frac{\epsilon_{\text{model}}}{1 - L_f} = \mathcal{O}(1), & 0 \le L_f < 1
\end{cases}
\]

当系统自带强阻尼项或具备稳定吸引子（如需求消耗或受限流转带来的收敛阻尼），其结构算子具备收敛映射属性。以我们在第
6 节 Beer Game 主实验中所观测的系统动力学环境为例，附录 A.3 的经验测算给出了 \(\hat L_f \approx 0.96\) 的局部估计，表明该工作区间内呈现出近似收缩特征；在这一经验事实下，多步绝对展开误差可被限制在 \(\mathcal{O}(1)\)
的常量上界内。该现象也与存量系统积分型状态更新的噪声平均效应一致，为上述误差收缩现象提供了解析意义上的物理直觉。这一理论结果不仅解释了第 6 节表 2（物理一致性）中观测到的显著稳定性提升，也与 BlackBox 在缺乏结构约束时出现的更高误差增长率形成了定量对照（即平均每步误差增量约 6.35\%，详见附录 A.3 测算）。

\hypertarget{ux957fux89c6ux91ceux622aux65adux8865ux507fux539fux7406-addressing-horizon-truncation-via-value-alignment}{%
\subsection{5.3 截断搜索的终端价值补偿原理 (Addressing Horizon Truncation via Value Alignment)}\label{ux957fux89c6ux91ceux622aux65adux8865ux507fux539fux7406-addressing-horizon-truncation-via-value-alignment}}

如果推演过程是稳定可控的，为何我们不利用 SD 结构化系统进行高深度甚至无穷深度规划？原因是在离散动作空间中，树搜索的计算复杂度依旧呈 \(\mathcal{O}(|\mathcal{A}|^H)\) 随深度呈指数剧增。因此，必须利用离线逼近的值函数 \(V_\psi\) 补偿极短视野处的截断（Truncation），避免高昂的延迟变量展开计算。

\textbf{命题 3：截断偏差与参数精确度的视界平衡 (The Horizon-Accuracy Trade-off). }
设任务的有效时间跨度（Effective Horizon）为 \(\tau\)。作为对比基线，我们考虑 \textbf{(1) Oracle MPC}：假设规划器拥有真实物理参数 \(\theta^\star\) 但不具备终端价值引导（终端值 \(V_H=0\)），截断深度为 \(H\)。由于短视探索，其必然引入截断偏差 (Truncation Bias) \(\le \frac{\gamma^H R_{\max}}{1-\gamma}\)。

相对地，考虑 \textbf{(2) SD-MCTS}：设 \(\hat{\theta}\) 为基于有限观测得到的带偏系统参数估计量，具有分布外估计误差界 \(\|\hat{\theta} - \theta^\star\| \leq \delta_\theta\)。由于性能约束，SD-MCTS 的展开深度同样被限制为极短的 \(H\)，但通过在叶节点引入离线价值网络代偿，其估值满足上界 \(\|V_\psi - V^*\|_\infty \leq \epsilon_V\)。

在策略行为分布中，由于 SD-MCTS 获得了结构保护且满足多步误差有界（命题 2），智能体 \textbf{(2) SD-MCTS} 产生的价值预测误差（Value Prediction Error）上确界将严格优于 \textbf{(1) 完美参数 Oracle MPC}，若满足如下充分条件：
\[
\underbrace{L_\theta \delta_\theta}_{\text{SD 参数误差导致的价值偏差}} + \underbrace{\gamma^H \epsilon_V}_{\text{折扣终端估计误差}} < \underbrace{\frac{\gamma^H R_{\max}}{1-\gamma}}_{\text{Oracle 的绝对视距截断盲区}}
\]
\emph{(其中 \(L_\theta\) 是预期累积奖励关于环境变量映射的全局 Lipschitz 常数).}

\textbf{理论推论}：这一不等式明确了``参数模型 + 短视窗探索 + 全局终端价值''架构在求解复杂长线系统规划时的必要性。即便离线拟合的网络 \(V_\psi\) 和经验识别量 \(\hat{\theta}\) 均包含固定的估计残差（不等式左侧项），只要物理系统的有效时间跨度 \(\tau\) 远大于可用搜索窗口 \(H\)，由于缺乏终端引导而丢失的深远影响（不等式右侧）便占据绝对主导。在此条件下，将计算资源从高成本的深度扩展中转移，转投于短视窗内的宽分支搜索，并辅以叶节点 $V_\psi$ 的自举代偿，是一项稳健的决策替代方案。

\hypertarget{ux89c4ux5212ux8d28ux91cfux7684ux6839ux672cux5deeux5f02q-ux4f30ux8ba1ux7684ux4e0dux53efux7ea6ux504fux5dee-irreducible-bias-in-q-estimation}{%
\subsection{5.4 规划质量的根本差异：Q 估计的不可约偏差 (Irreducible Bias
in
Q-Estimation)}\label{ux89c4ux5212ux8d28ux91cfux7684ux6839ux672cux5deeux5f02q-ux4f30ux8ba1ux7684ux4e0dux53efux7ea6ux504fux5dee-irreducible-bias-in-q-estimation}}

前三个命题共同表明，SD-MCTS 与黑盒 MCTS 在规划质量上的差异不仅体现在方差收敛速度，更体现在由世界模型失配导致的偏差是否可消除。

\textbf{命题 4：黑盒世界模型的 Q 估计存在不可约偏差。} 设 $\hat{Q}_{n}(s,a)$ 为 MCTS 在动作 $a$ 上经过 $n$ 次 rollout 后得到的估计，$Q_H^\pi(s,a)$ 为真实的 $H$ 步截断 Q 值。其误差可写为
\[
\hat{Q}_{n}(s,a)-Q_H^\pi(s,a)=b_H(s,a)+\varepsilon_n(s,a),\qquad \varepsilon_n(s,a)=\mathcal{O}_p(n^{-1/2}),
\]
其中 $b_H(s,a)$ 为模型结构失配产生的确定性偏差，$\varepsilon_n(s,a)$ 为可随采样次数衰减的随机项。

对于黑盒 MLP 世界模型，若其有效 Lipschitz 常数满足 $\gamma L>1$，由命题 2 的多步误差传播可得，偏差项随规划深度呈指数放大：
\[
\left|b_H^{\mathrm{BB}}(s,a)\right|\le C_{\mathrm{BB}}(\gamma L)^H,
\]
其中 $C_{\mathrm{BB}}$ 由世界模型单步误差、奖励 Lipschitz 常数、终端价值逼近误差及 rollout 分布共同决定，但与 $n$ 无关。因而即使 $n\to\infty$，随机项 $\varepsilon_n$ 消失后，$\left|b_H^{\mathrm{BB}}(s,a)\right|$ 仍保留为不可约系统误差。

相比之下，SD-MCTS 的结构约束将预测轨迹限制在物理可行域内，并显著抑制多步误差累积。对应地，
\[
\left|b_H^{\mathrm{SD}}(s,a)\right|\le C_{\mathrm{SD}},
\]
且在结构完全匹配、转移确定且终端价值估计无误差的理想条件下，有 $b_H^{\mathrm{SD}}(s,a)\equiv 0$（即系统性误差完全消失）。

\textbf{推论（效率差距的根因）。} SD-MCTS 的样本效率优势主要来源于结构化建模对偏差项的抑制，而非随机波动或超参数的偶然匹配。当 $n$ 增大时，两类方法的方差项均衰减，但黑盒模型的不可约偏差 $\mathcal{O}((\gamma L)^H)$ 仍限制其最终规划质量。这一分析为第 6 节中观察到的实验现象提供了理论解释：缺乏结构约束的黑盒模型即使增加训练或规划预算，其性能提升仍会受到系统性偏差的限制；相比之下，SD-MCTS 更容易在低样本和长时延任务中保持规划优势。完整的 bias-variance 分解见附录 A.7。

\end{enumerate}

\subsubsection{6.2.2 规划内部轨迹一致性 (Planning-Internal Trajectory Fidelity)}

\textbf{规划内部轨迹一致性保证}：模型基强化学习（MBRL）的性能很大程度上取决于规划器对未来轨迹分布的保真程度。MCTS
在搜索树内构建多步展开轨迹时，模型输出的想象状态（imagined
states）如果发生物理失真（如产生负库存、违反守恒方程），就会系统性地污染树内的价值估计和路径回报，导致规划偏差。\textbf{此处关键的区分是}：动作掩码（action
masking）或事后裁剪（post-hoc clamping）只能保证最终执行动作的合法性，却无法修复
MCTS 搜索树内部想象轨迹的物理失真。换言之，这类方法只能约束“最终输出什么动作”，却不能改变搜索过程中已经生成并参与回传的非物理状态，因此树内价值估计的系统性偏差仍会被保留下来。即：\textbf{输出层的事后修补（patch）不能替代模型动力学层面的结构约束。}

MLP。这样，二者在搜索树内部想象轨迹上的差异，便可更直接地归因于结构约束本身，而非规划算法或价值补偿机制的改变。

表明，结构约束会显著影响多步误差的传播方式。全连接 BlackBox
模型的初始误差更高，且误差随展开步数持续上升；按附录 A.3

步翻倍。相比之下，SD-MCTS
模型的误差曲线始终维持在极低水平，在观测窗口内基本不随步数增长。这说明，显式流转约束和非负可行域限制能够有效抑制多步展开中的误差累积。

基于这种近似常数级的误差界，SD-MCTS
在规划时可以显著减轻长视野展开带来的复合噪声，也为在较浅规划深度下结合叶节点价值估计提供了更稳定的前提。

\hypertarget{ux9762ux5bf9ux7ed3ux6784ux7a81ux53d8ux7684ux96f6ux6837ux672cux56e0ux679cux5e72ux9884-zero-shot-transfer-via-causal-intervention}{%
\subsection{6.4 面对结构突变的零样本因果干预 (Zero-shot Transfer via
Causal
Intervention)}\label{ux9762ux5bf9ux7ed3ux6784ux7a81ux53d8ux7684ux96f6ux6837ux672cux56e0ux679cux5e72ux9884-zero-shot-transfer-via-causal-intervention}}

在前述 Beer Game 的样本效率与误差泛化证据之外，我们进一步检验该框架在结构突变下的适应能力。当供应链中出现节点失效或链路中断等突发变化时，缺乏可编辑结构的黑盒模型通常难以及时利用已知干预信息。为此，我们在四级啤酒游戏中构造了两类可观测的\textbf{因果干预实验}：容量冲击与链路中断（训练样本预算为 5000 步，评估基于 3 个随机种子）。

\subsubsection{6.4.1 干预设定与总体结果}

\textbf{核心设定}：干预事件本身对决策者是可观测的，即其发生时点与作用位置已知，例如供应链中的容量受限或链路中断可以作为外部信息被明确获知。困难之处不在于识别干预是否发生，而在于智能体此前从未在该参数分布或图拓扑下接受训练。

具体而言，我们在每个 episode 中施加两类结构突变：一类是在 \(t \geq 15\) 后将产能约束下调的容量冲击（capacity shock），另一类是在 \(10 \leq t \leq 20\) 区间内切断关键订单链路的链路中断（communication severed）。

我们对以下 3 种变体的累计成本以及它们世界模型的绝对多步预测误差（RMSE）进行了零样本评估：

\begin{itemize}
\item \textbf{SD}：本文方法，在受到干预时对内部转移计算图施加与外部事件一致的 \(do()\) 式结构修改。
\item \textbf{SD\_no\_update}：同一预训练的 SD 模型，但拒绝进行内部图响应修改，用以剥离图编辑的作用。
\item \textbf{BlackBox (BB)}：基于同等数据训练的无结构 MLP 的 MCTS 世界模型。
\end{itemize}

为考察结构编辑在此类干预下的作用，我们首先比较三种变体在两类结构突变中的累计成本表现，结果如图 4 所示。

\begin{enumerate}
\item \textbf{结构先验与结构编辑带来两层增益。} 即使不进行图编辑，SD\_no\_update 仅凭结构化转移与守恒约束，在两类干预场景下也均明显优于 BB：在容量冲击（capacity shock）下，累计成本由 3585 降至 1791；在链路中断（communication severed）下，累计成本由 4059 降至 2216。这说明结构先验本身已经能够降低 OOD 条件下的规划失真。在此基础上，SD 进一步将已知干预直接写入内部转移过程，相比 SD\_no\_update 又继续改善：在容量冲击下由 1791 降至 1331，在链路中断下由 2216 降至 1865，对应额外提升约 25.7\% 与 15.9\%。这表明结构编辑能够进一步利用外部干预信息提升零样本适应能力。

\item \textbf{守恒结构仍能提供更可靠的规划依据。} 在链路中断（communication severed）场景下，\texttt{SD\_no\_update} 的多步预测误差（11.46）已经接近 BB（13.87），但累计成本仍明显更低（2216 vs 4059）。这说明，即使未显式更新内部图结构，结构化模型保留的守恒关系仍能提供更合理的状态表征。换言之，\texttt{SD\_no\_update} 虽然会错估局部库存分布，但总体流转关系仍受守恒约束，因此规划不会偏离基本物理逻辑；相比之下，BB 一旦违反守恒，就可能在预测中产生并不存在的库存或流量，从而系统性高估某些动作的收益。

\item \textbf{结构编辑显著降低了跨种子波动。} 在链路中断（communication severed）场景下，\texttt{SD\_no\_update} 的多步预测误差跨种子标准差达到 \textbf{±4.18}，说明在未更新内部结构时，不同随机种子会对未见干预产生较不一致的预测结果。相比之下，SD 在显式写入干预后，其 RMSE 跨种子标准差降为 0.00。这表明，当干预事件本身已知时，显式结构更新不仅能够改善平均性能，也能够减少不同随机种子之间的响应分歧。
\end{enumerate}

\textbf{小结}：以上对照表明，干预下的性能改善主要来自两个层面。其一，即使不进行结构编辑，\texttt{SD\_no\_update} 仅凭结构化转移与守恒约束，也已在两类场景下明显优于 BB，这可视为结构先验本身带来的收益。其二，在此基础上，SD 再将已知干预写入内部转移过程，相比 \texttt{SD\_no\_update} 继续取得约 15.9\%\textasciitilde{}25.7\% 的额外改善，说明结构编辑能够进一步利用外部干预信息提升零样本适应能力。以容量冲击（capacity shock）为例，累计成本由 BB 的 3585 依次降至 \texttt{SD\_no\_update} 的 1791 和 SD 的 1331，较清楚地体现了这两层作用的叠加。

\hypertarget{sub-cartpole-rescue}{%
\subsection{6.5 Cartpole-Swingup：公开基准上的样本效率与敏感状态稳健性 (Public-Benchmark Validation under Sensitive States)}\label{sub-cartpole-rescue}}

在前述 Beer Game 系列实验之外，我们进一步转向 DeepMind Control Suite 的标准任务 \texttt{Cartpole-Swingup}
进行评估，以补充公开基准上的对比证据。虽然该任务不具有 Beer Game 那样直观的库存流转语义，但其 SD 构成同样是明确的：小车位置、杆角及其速度状态可视为连续存量，控制输入以及由重力、惯性耦合决定的状态变化率项，可视为驱动这些存量演化的“流”，而“偏离竖直平衡会进一步放大后续修正难度”的机制则体现了反馈回路。该任务的动力学可由经典倒立摆方程刻画；同时，系统在接近竖直平衡时对状态误差极为敏感，因此也为检验

\textbf{因此，表 4 中的 Cartpole 主结果不能简单归因于某一个单独组件}：更合理的解释是，结构化世界模型负责提供可信的局部动力学，价值网络负责补偿短视截断，而在线 MCTS 则在敏感状态附近进一步改善动作选择质量。正是这三者的结合，才构成了表 4 中所报告的 Cartpole 主结果，也使得该结果更不容易被解释为仅仅来自某个偶然有利的单个种子或单步启发式的偶然收益。

\textbf{实验结果}：在当前已完成的 50k 三种子评估中，结构化 Hopper 扩展取得了 \(32.93 \pm 13.03\) 的均值回报，三个种子分别达到 \(24.78\)、\(22.70\) 与 \(51.32\)。作为对照，TD-MPC2 在该任务上的官方可核验结果为 100k 步设定下的 \(13.6 \pm 10.4\)，DreamerV3 在 100k 步设定下为 \(9.7 \pm 13.6\)。这表明，即使面对 \texttt{Hopper-Hop} 这一更高难度、奖励信号更稀疏的公开基准，该实验仅用 50k 步真实环境交互，已取得高于两项公开基线在 100k 步口径下的平均回报。}

{\color{red}
\textbf{结果分析}：与 Cartpole 相比，\texttt{Hopper-Hop} 的难点在于，成功跳跃通常并不是由单一步动作直接触发，而是依赖一串先后衔接的中间条件，例如机体抬升、支撑逐步卸载、离地间隙形成、姿态保持稳定以及竖直速度建立。这些条件大多先于环境中的显式奖励出现，因此若求解过程只围绕训练早期较弱的环境回报展开，算法就很难在低预算阶段稳定辨认哪些状态正在朝成功轨迹演化。该实验中，结构化世界模型将高度、支撑、离地间隙、压缩与摆动等机制量显式表示出来，而规划奖励、课程式塑形（Curriculum Shaping）与辅助监督则进一步把这些结构量转化为可用于动作评估的偏置，因此即使在环境奖励尚不充分时，求解过程仍能较早围绕正确方向组织探索。}

{\color{red}
\textbf{进一步的启发}：该实验提示，在那些成功行为依赖阶段性条件逐步满足的任务中，结构化收益不应仅理解为“把世界模型从黑盒换成结构化形式”。更关键的因素在于，这类任务的成功往往依赖若干具有先后关系的结构条件；如果这些条件只体现在状态递推里，而不进一步进入动作评估、搜索偏置与训练信号，那么求解器在早期仍主要依赖稀疏的终局奖励，结构知识就难以转化为稳定的低预算收益。相反，当这些结构量同时进入建模与求解两侧时，算法便能够在奖励尚弱的阶段优先保留那些更可能通向成功轨迹的候选动作。这也说明，在更复杂的任务上，结构化方法的后续发展方向很可能不仅是继续改进世界模型表达，还包括将更多求解过程纳入结构化空间中完成。}

\hypertarget{ux8ba8ux8bbaux4e0eux7ed3ux8bed-discussion-and-conclusion}{%
\section{7 讨论与结语 (Discussion and
Conclusion)}\label{ux8ba8ux8bbaux4e0eux7ed3ux8bed-discussion-and-conclusion}}

本文提出了 SD-MCTS 框架，将结构化世界模型、有限视界树搜索与终端价值补偿结合起来，用于已知系统结构可被显式利用的低样本决策问题。全文的核心结论可以概括为：当任务中存在可设计在模型中的因果拓扑、守恒关系或解析动力学时，将学习重点压缩到少量未知参数与终端价值估计，能够显著降低获得可用规划性能所需的真实交互成本。

\revdel{Beer Game 与 Cartpole-Swingup 的结果表明，这类方法并不是对黑盒 MBRL 或传统 MPC 的简单替代，而更像二者之间的一种中间方案：一方面，结构化世界模型有助于抑制多步误差传播和搜索树内部的物理失真；另一方面，终端价值补偿又能够缓解浅搜索带来的截断损失。在干预事件可观测且能够映射为结构方程局部修改的场景下，模型的可编辑性还进一步支持了零样本结构适应。换言之，本文更想强调的是：\textbf{在结构先验明确的任务中，规划质量的提升很大程度上来自偏差控制，而不仅是来自更大模型或更多样本。}}
\revadd{Beer Game、Cartpole-Swingup 与 Hopper-Hop 的结果共同表明，这类方法并不是对黑盒 MBRL 或传统 MPC 的简单替代，而更像二者之间的一种中间方案：一方面，结构化世界模型有助于抑制多步误差传播和搜索树内部的物理失真；另一方面，终端价值补偿与必要的结构化求解偏置又能够缓解浅搜索带来的截断损失。在干预事件可观测且能够映射为结构方程局部修改的场景下，模型的可编辑性还进一步支持了零样本结构适应；而在 Hopper 这类成功行为依赖阶段性条件逐步满足的任务中，结构收益则进一步显示出“建模侧结构化”与“求解侧结构化”相互配合的重要性。换言之，本文更想强调的是：\textbf{在结构先验明确的任务中，规划质量的提升很大程度上来自偏差控制，而不仅是来自更大模型或更多样本。}}

\hypertarget{ux73b0ux5b9eux90e8ux7f72ux542bux4e49-online-overhead}{%
\subsubsection{计算开销与部署讨论}\label{ux73b0ux5b9eux90e8ux7f72ux542bux4e49-online-overhead}}

除样本效率外，在线计算开销也是实际应用中的一个重要考量。就本文方法而言，世界模型的可训练部分主要集中在少量具有物理意义的参数上，在线阶段的主要开销来自有限视界搜索与少量结构化一步前推，而不是大规模潜空间展开。与依赖高维隐状态模型的黑盒世界模型相比，这种结构化表示在参数规模和单步更新路径上通常更轻量。

不过，本文并未对真实部署场景下的时延、吞吐或硬件占用进行专门测量，因此这里更适合将其理解为一种\textbf{复杂度层面的讨论}，而非对特定实时约束的实证结论。更准确地说，本文结果表明：在结构已知、样本昂贵且解释性重要的任务中，结构化世界模型有望在保持较低样本需求的同时，避免引入过重的模型计算负担；至于其在特定工业系统中的实际部署表现，仍需进一步的工程验证。

\hypertarget{ux9884ux5148ux5e94ux5bf9ux53efux80fdux8d28ux7591ux4e3aux4ec0ux4e48-action-masking-ux4e0dux591fux7528}{%
\subsubsection{为什么动作掩码（Action Masking）不能替代结构约束？}\label{ux9884ux5148ux5e94ux5bf9ux53efux80fdux8d28ux7591ux4e3aux4ec0ux4e48-action-masking-ux4e0dux591fux7528}}

一个自然的问题是：如果黑盒模型在预测过程中出现物理违规，是否可以通过动作掩码（action masking）、状态裁剪（state clamping）等事后手段进行修补，从而削弱结构约束的必要性？从本文的角度看，这类手段可以提升\textbf{最终执行动作}的可行性，但仍不足以替代对\textbf{搜索树内部想象轨迹}的结构约束。

\textbf{原因在于，动作掩码（action masking）关注的是动作可行性（action feasibility），而本文更关心的是轨迹动力学保真（trajectory fidelity）。} 在 MCTS 中，规划器需要依赖世界模型对未来状态进行多步展开；如果搜索树内部生成的想象状态已经违反守恒关系、非负约束或其他基本结构条件，那么后续的价值回传和动作选择就会从一开始建立在失真的轨迹上。此时，即便最终输出动作经过额外筛选而保持合法，树内误差也已经对规划质量产生了系统性影响。

同理，状态裁剪也是对预测结果的事后修补，而不是对动力学本身的修正。它虽然可以在数值上强行把状态拉回可行区域，但并没有恢复原有的守恒流转关系，因此仍可能在规划过程中引入额外的隐式动力学偏差。第 6.2.2 节的结果正说明了这一点：真正影响规划质量的，不只是动作是否可执行，更是搜索树内部的想象轨迹是否保持了与环境一致的结构关系。

\hypertarget{ux5c40ux9650ux6027ux4e0eux5f00ux653eux6311ux6218-limitations}{%
\subsubsection{局限性与开放挑战
(Limitations)}\label{ux5c40ux9650ux6027ux4e0eux5f00ux653eux6311ux6218-limitations}}

不过，当前框架依然存在一些局限性，有待在未来的工作中持续攻克：

\begin{enumerate}
\item \textbf{结构已知假设 (The Known Structure Assumption)}：本文框架依赖一个基本正确的存量--流量或解析动力学骨架。这一设定适用于具有明确机理约束的工程系统；但如果先验结构本身存在遗漏或系统性偏误，预测与规划质量仍会受到限制。未来一个值得继续推进的方向，是将结构参数辨识与因果结构修正结合起来，而不只停留在固定拓扑下的参数学习。
\item \textbf{理想动力学假设与未建模残差 (Idealized Dynamics and Residual Components)}：本文的研究重点，是验证结构化世界模型、终端价值补偿与结构编辑三者结合后，能否在低样本条件下改善规划质量，而不是在本篇中直接追求一个尽可能全面、尽可能高性能的通用学习模型。为突出这一核心主张，本文实验所使用的数据均来自理想仿真器，因此建模时默认训练数据中不存在显著观测噪声，也不额外包含结构化动力学主干之外的未覆盖成分。在这一设定下，直接利用结构化世界模型进行参数辨识是合适的；但在更普遍的现实问题中，系统往往呈现“主体动力学机制 + 随机扰动 + 未建模残差”并存的形态。对于这类情形，仅依赖纯结构主干可能不足以完整吸收偏差，未来更值得考虑的方向，是在保留结构化动力学主体的前提下，引入残差网络等补充模块，对未被显式建模的成分进行学习。
\item \textbf{大规模动作空间下的搜索扩展性 (Scalability to Massive Actions)}：本文的树搜索在当前任务规模下是可行的，但当动作空间进一步扩大，尤其是进入高维连续控制时，离散化分支与搜索宽度都会迅速增加。此时可能需要将本文框架与更强的候选动作生成机制、策略引导搜索或分层规划方法结合，才能保持可接受的计算成本。
\end{enumerate}

\hypertarget{a.1-ux5b9eux9a8cux73afux5883ux8bbeux8ba1ux7ec6ux8282}{%
\subsection{A.1
任务中的 SD 实例化与环境定义}\label{a.1-ux5b9eux9a8cux73afux5883ux8bbeux8ba1ux7ec6ux8282}}

\paragraph{四级啤酒游戏供应链（Beer Game）.}
\revdel{在四级啤酒游戏中，SD 建模对象是具有显式延迟的物料与订单流转系统。工厂、分销商、批发商和零售商构成串联拓扑，终端需求仅在零售商侧被观测。就 SD 的基本构成而言，库存与积压是核心状态量；到货、发货、下单与需求满足构成流量；库存偏低、积压升高以及上游交付延迟共同影响后续订货决策，从而形成闭环反馈。本文世界模型在每一级节点上显式给出差分更新，并保留非负约束、发货受库存限制以及容量上限等结构条件，因此结构突变实验中的容量冲击与链路中断，都可以自然地表示为对容量参数或流量通道的直接干预。}

{\color{red}
\begin{enumerate}
\item \textbf{状态表示：} SD 世界模型直接按环境的显式库存系统书写，内部状态为 \(26\) 维。四级节点各自包含库存 \(I\)、积压 \(B\)、两格在途发货管道 \(\text{ship}[0{:}1]\) 与两格订单信息管道 \(\text{order}[0{:}1]\)，此外还包含当前时间步与当期客户需求。
\item \textbf{SD 语义对应：} 库存与积压对应 stock，在途发货、订单传递、终端需求满足与工厂补产对应 flow；“库存不足 \(\rightarrow\) 积压上升 \(\rightarrow\) 后续订货调整”构成带时滞的 feedback 回路。
\item \textbf{结构方程：} 一步转移不由黑盒网络回归，而按固定顺序执行：先接收 \(\text{ship}[0]\) 到货，再将发货与订单管道整体移位；随后由零售端注入外部需求、其余各级接收上游延迟订单；接着依据 \(\min(\text{inventory},\text{backlog})\) 规则完成发货，并将上游实际发货写回下游在途管道；最后由工厂按产能上限生成新的补产流。
\item \textbf{可学习参数：} 论文主结果中的 Beer Game SD 模型不学习拓扑与时滞结构，而固定四级串联系统、\(\tau_{\text{info}}=2\)、\(\tau_{\text{ship}}=2\)、成本函数形式及基线产能约束，仅学习 \(3\) 个标量参数，即 \(\text{demand\_low}\)、\(\text{demand\_high}\) 与 \(\text{demand\_step\_time}\)。
\item \textbf{硬约束：} 为保持物理可行性，库存、积压、在途发货与在途订单在每一步更新后都被截断到非负域，工厂补产额外受 \(\text{production\_capacity}\) 约束。因此，守恒关系与可行域约束始终通过显式差分方程维护，而不是隐含在参数矩阵中。
\item \textbf{干预接口：} 容量冲击实验通过在 \(t\ge 15\) 时将工厂产能上限由 \(20\) 改写为 \(2\) 实现；链路中断实验通过在 \(10\le t\le 20\) 时将批发商订货流强制置零实现。两类干预都表现为对结构方程局部项的直接编辑，因此 SD 模型可以在不重训神经网络的前提下完成测试时响应。
\end{enumerate}
}

\paragraph{DMControl Cartpole-Swingup.}
\revdel{在 Cartpole-Swingup 中，SD 结构不再表现为离散物流网络，而表现为受解析动力学约束的连续演化系统。小车位置、速度、杆角与角速度可视为随时间积分演化的状态量；控制输入以及由重力、惯性和耦合关系决定的状态导数，共同决定这些状态量在离散时间下的一步更新。本文结构化世界模型固定经典小车-倒立摆动力学方程的结构形式，仅对重力、质量、杆长等少量参数进行辨识，因此其结构先验来自动力学骨架本身，而不是完全依赖数据去拟合状态转移关系。该任务要求系统从悬垂状态完成摆起并维持近竖直平衡，因而适合检验在敏感状态附近，结构化动力学与在线规划能否共同提升决策稳健性。}

{\color{red}
\begin{enumerate}
\item \textbf{观测与内部状态：} SD 世界模型采用连续解析动力学。DMControl 原始观测为 \([x,\cos\theta,\sin\theta,\dot x,\dot\theta]\)，其中 \(\theta=0\) 表示竖直向上、\(\theta=\pi\) 表示自然下垂；模型先用 \(\operatorname{atan2}(\sin\theta,\cos\theta)\) 将观测还原为内部状态 \([x,\theta,\dot x,\dot\theta]\)，再在该显式物理状态上执行一步预测。
\item \textbf{动作解释：} 动作为区间 \([-1,1]\) 内的标量控制输入，在模型内乘以 actuator gear \(=10\) 后解释为小车所受水平驱动力。论文评测时再将连续动作离散为 \(11\) 个搜索分支，以便与当前 MCTS 实现对接。
\item \textbf{结构方程：} 环境动力学固定为带阻尼的小车--倒立摆牛顿方程，并使用与 MuJoCo 配置一致的 RK4 积分器、时间步长 \(dt=0.01\) 做离散推进。状态导数由重力、杆端惯性耦合、车体与摆杆质量分配以及极小的滑轨/转轴阻尼共同决定。
\item \textbf{可学习参数：} 论文口径的 Cartpole 结果中，重力参数固定为 \(9.81\)，仅学习 \(3\) 个标量参数，即车体质量 \(\text{masscart}\)、摆杆质量 \(\text{masspole}\) 与摆杆质心半长 \(\text{length}\)。这些参数均通过 softplus 与下界截断保持为正值，以避免非物理估计。
\item \textbf{固定物理常数：} 滑轨阻尼 \(5\times10^{-4}\) 与转轴阻尼 \(2\times10^{-6}\) 按 MuJoCo 配置固定，不作为学习对象。这样可以保证搜索树内所有想象轨迹共享同一动力学骨架，模型只需校准少数与具体随机种子相关的物理常数。
\item \textbf{与价值补偿的分工：} 与 Beer Game 类似，一步转移完全由解析动力学积分给出，终端价值网络只负责补偿有限规划视界后的长期回报，而不替代动力学本体。由于摆起任务在杆角接近竖直时对模型误差极其敏感，Cartpole 因而构成了检验 SD 结构先验是否能稳定支撑在线规划的连续控制实例。
\end{enumerate}
}

\paragraph{DMControl Hopper-Hop.}
{\color{red}
\begin{enumerate}
\item \textbf{观测与内部状态：} Hopper 实验采用 DMControl 的状态观测输入，原始观测为 \(15\) 维，包含根部高度与姿态、四个关节角、线速度与角速度，以及 toe/heel 两个接触读数。SD 世界模型并不直接把这 \(15\) 维观测当作规划状态，而是先编码为同样 \(15\) 维的机制状态：
\[
\begin{aligned}
&[\text{height},\text{vx},\text{vz},\text{pitch},\text{pitch\_rate},\text{compression},\\
&\text{compression\_rate},\text{swing},\text{swing\_rate},\text{foot\_angle},\\
&\text{foot\_rate},\text{support},\text{stance\_mix},\text{impact},\text{clearance}].
\end{aligned}
\]
其中，height、compression、support 与 clearance 对应任务中的关键结构量，vx、vz 与各类 rate 则描述连续演化趋势。
\item \textbf{动作解释：} 动作为连续控制输入，先被分解为 drive、posture 与 foot 等控制分量，再分别作用到水平/竖直加速度、机体姿态、压缩量、摆动量与足端角等结构变量的更新中。也就是说，动作并不直接驱动一个无语义 latent 转移器，而是通过若干具有物理含义的中间通道影响一步递推。
\item \textbf{系统动力学方程：} Hopper 实验的一步转移主要由显式系统动力学主干给出。模型根据动作构造 \(x/z\) 加速度、姿态变化、压缩/摆动/足端角的速率更新，并以欧拉积分得到下一步结构状态。更新后再通过 `project\_state()` 将高度、接触强度、姿态角与冲击量投影回合法域。
\item \textbf{可学习参数：} 在该 Hopper 实现中，新增的可学习量主要是 \(11\) 个显式标量参数，即 `control\_scale` 的 \(4\) 个分量与 `rate\_damping` 的 \(7\) 个分量。与之对应，被替代的原 TD-MPC2 黑盒 latent dynamics 模块参数量为 \(300{,}128\)。
\item \textbf{结构约束与奖励设计：} 环境奖励显式对齐为 `standing \times hopping`，其中 standing 由高度阈值给出，hopping 由前向速度是否达到任务目标决定。与此并行，规划器在叶节点评估时使用带 viability gate 的 planning reward：在真实奖励基础上，进一步考虑高度、姿态、支撑、离地间隙、向上速度与减粘连接触等结构信号，以缓解短规划视界下“只会站立或黏地前冲”的局部最优。论文所用配置同时采用课程式塑形（Curriculum Shaping）混合策略，初始塑形权重为 \(0.5\)，并在 \(10\text{k}\) 至 \(30\text{k}\) 训练步之间衰减至 \(0.25\)。
\item \textbf{与求解层的分工：} Hopper 并未单独实现新的规划器，而是保留 TD-MPC2 的求解层接口，仅将世界模型替换为 SD 版本。具体而言，`encode / next / reward / pi / Q` 五个接口与原框架保持一致，训练阶段另对 `height\_head` 增加系数为 \(0.05\) 的辅助监督损失，使高度相关塑形分量不再处于无梯度漂移状态。因而，这一 Hopper 版本本质上属于“结构主干负责机制表达，原有求解闭环负责在线决策”的混合实现。
\end{enumerate}
}

\hypertarget{a.3-beer-game-supplementary-results}{%
\subsection{A.3 Beer Game 的补充结果与指标定义}\label{a.3-beer-game-supplementary-results}}

\paragraph{表 2 中“违规率”的定义.}
正文表 2 统计的并不是 episode 级违规频率，而是搜索树\textbf{内部想象状态}的违规比例。具体地，若一次 MCTS 展开产生的某个想象状态在前 \(24\) 个物理维度上存在任一分量小于 \(-10^{-6}\)，则记为一次违规；时间步和当前需求这两个元数据维度不参与统计。因此，
\[
\text{violation rate}
=
\frac{\text{violating imagined states}}{\text{all imagined states}}.
\]
在同一受控协议下（训练预算 \(3000\)、三随机种子、每种子 \(10\) 个评测 episode，且固定规划器与终端价值网络），SD-MCTS 的违规率为 \(0.00\%\pm0.00\%\)，BB-MCTS 为 \(93.66\%\pm1.95\%\)。

\paragraph{多步展开 RMSE 的定义与补充结果.}
正文图 3 对应的误差指标，是从同一真实状态出发，将模型自回归展开 \(H\) 步后，与真实环境在相同步数上的物理状态做逐维比较得到的均方根误差（RMSE）。在 Beer Game 的确定性主环境中，SD 世界模型的状态更新与环境规则一致，因此多步展开误差保持为 \(0\)；相对地，BB 模型在同一分布内设置下的平均 RMSE 从 \(H=1\) 时的 \(0.345\) 上升到 \(H=10\) 时的 \(1.343\)，并在 \(H=50\) 时增至 \(8.412\)。对其误差曲线做指数拟合时，平均增长率约为 \(6.35\%\) 每步，这与正文关于误差链式累积的分析一致。

\paragraph{经验 Lipschitz 常数的测算.}
为呼应正文第 5 节关于收缩映射的讨论，我们对 Beer Game 主实验中的结构化一步动力学映射做了经验测算。具体地，在主实验状态分布上抽取一批状态--动作对 \((s,a)\)，并仅在物理状态维度上施加小扰动 \(\delta s\)，以有限差分方式近似计算局部增量比值
\[
\frac{\|f(s+\delta s,a)-f(s,a)\|}{\|\delta s\|}.
\]
随后对这些局部比值取样本统计量，可得一个经验 Lipschitz 常数估计 \(\hat{L}_f \approx 0.96\)。这里的 \(\hat{L}_f\) 不是严格解析上界，而是主实验工作区间内一步映射局部收缩性的经验近似，不应理解为对全局收缩性的严格证明。该结果仅说明，在这类以守恒更新为主、并带有交付与需求消耗阻尼的系统中，局部误差传播总体上未表现出发散式放大，从而为正文中“结构约束能够抑制多步误差累积”的判断提供了额外佐证。

\hypertarget{a.4-structural-intervention-protocol-and-results}{%
\subsection{A.4 结构突变干预协议与完整结果}\label{a.4-structural-intervention-protocol-and-results}}

正文第 6.4 节的结构突变实验，统一在\textbf{无干预环境}中完成训练，仅在测试阶段注入训练期内未出现的结构变化。本文使用两类干预：其一为容量冲击，即工厂产能自 \(t\ge 15\) 起由 \(20\) 降至 \(2\)；其二为链路中断，即批发商的订货通道在 \(10\le t\le 20\) 期间被强制置零。三种比较方法分别为：\textbf{SD}，在获得干预信息后显式改写内部结构方程；\textbf{SD\_no\_update}，保留原结构不变，仅依赖既有模型推断；\textbf{BB}，使用黑盒世界模型，不具备结构编辑能力。

累计成本与预测误差均在同一测试协议下统计，其中累计成本沿用正文表 3 的口径，数值越小表示表现越好；预测误差则采用预热 10 步、预测视界 15 步的多步 RMSE，以覆盖两类干预真正生效的时间窗口。按三随机种子的均值计算，在容量冲击场景下，SD、SD\_no\_update 和 BB 的累计成本依次为 \(1330.7\)、\(1791.0\) 和 \(3584.6\)，对应的多步 RMSE 依次为 \(0.00\)、\(5.02\) 和 \(12.35\)；在链路中断场景下，三者的累计成本依次为 \(1864.5\)、\(2216.1\) 和 \(4059.4\)，对应的多步 RMSE 依次为 \(0.00\)、\(11.46\) 和 \(13.87\)。这些结果说明，仅有结构化世界模型还不够，干预发生后能否按已知信息及时改写结构，仍然会显著影响 OOD 条件下的规划质量。

\hypertarget{a.5-cartpole-protocol-and-ablation}{%
\subsection{A.5 Cartpole 公开基准评测设置、稳定性与补充消融}\label{a.5-cartpole-protocol-and-ablation}}

\paragraph{评测设置与共享价值先验.}
正文 Cartpole 结果采用两阶段设置：先在开发种子 \(\{10,21,30,55,63,72,95\}\) 上训练共享价值先验，再在目标种子 \(\{0,42,84\}\) 上分别微调。对应的真实环境交互预算为共享先验预训练 \(35{,}000\) 步，加上单个目标种子的微调 \(5{,}000\) 步；本文评测采用 \(11\) 个离散动作分支、动作重复步数为 2、每个种子 5 个评测 episode 的设置。

\paragraph{结果与稳定性补充.}
正文表 4 仅给出三种子聚合均值与最差种子回报。对应的逐种子结果为：seed \(0\) 为 \(772.8\pm33.5\)，seed \(42\) 为 \(817.9\pm29.6\)，seed \(84\) 为 \(818.2\pm18.8\)。与此同时，系统辨识阶段恢复的杆质量相对误差分别为 \(2.69\%\)、\(0.87\%\) 和 \(0.86\%\)。这些补充结果说明，在本文结果口径下，动力学参数恢复与最终控制表现都未出现明显失稳的种子。

\paragraph{补充消融：去掉树搜索后的 1-step 对照.}
为区分“结构化世界模型 + 终端价值”与“在线树搜索”各自的贡献，我们在完全相同的 checkpoint 和评测协议下，将在线决策替换为一步前瞻加终端价值评估的 1-step 对照，不再执行树搜索。该对照在三种子上的结果分别为 \(751.0\pm7.4\)、\(781.9\pm81.3\) 和 \(806.7\pm19.6\)，整体均值为 \(779.9\)。因此，在保持同一结构化动力学与价值网络权重不变时，完整 SD-MCTS 仍带来约 \(+23.0\) 的均值提升；同时，由于这里的 MCTS 采用离散动作分支实现，这一增益应理解为在保守实现条件下观测到的补充证据。

\hypertarget{a.6-complexity-and-reproducibility-index}{%
\subsection{A.6 算法复杂度与复现索引}\label{a.6-complexity-and-reproducibility-index}}

从实现角度看，SD-MCTS 的主要在线开销来自有限视界树搜索。在离散动作设置下，其计算量主要由动作分支数、搜索深度和模拟次数共同决定，可近似写为 \(\mathcal{O}(n_{\text{sims}} \cdot H \cdot |\mathcal{A}|)\)。Beer Game 的动作空间本身离散，因此这一复杂度表达较为直接；Cartpole 则需先将连续动作离散化为有限分支，因此其实际计算开销除受 \(n_{\text{sims}}\) 与 \(H\) 影响外，还与离散动作分支数以及动作重复步数（action repeat）有关。

为便于独立复现，本文同时提供独立的评审附件包
\path{Attachments/}。该附件包不依赖作者工作目录中的绝对路径，而按
\path{code/} 与 \path{data/}

\hypertarget{a.7-q-ux4f30ux8ba1ux7684-bias-variance-ux5206ux89e3ux63a8ux5bfc-bias-variance-decomposition-of-q-estimation}{%
\subsection{A.7 固定 rollout 策略下的 Q 估计偏差-方差分解推导 (Bias-Variance
Decomposition of
Q-Estimation)}\label{a.7-q-ux4f30ux8ba1ux7684-bias-variance-ux5206ux89e3ux63a8ux5bfc-bias-variance-decomposition-of-q-estimation}}

本节在固定 rollout 策略的简化设定下，对 §5.4 命题 4 给出一版可严格化的推导。首步动作固定为 \(a\)，后续动作由固定 rollout 策略 \(\pi\) 生成；同时，将 \(n\) 次模拟视为在该固定 rollout 分布下得到的样本。该设定旨在隔离世界模型误差对截断回报偏差的影响，因此不涉及完整 MCTS 自适应树策略的收敛性分析。

\textbf{设定}：令真实轨迹满足 \(s_0=s\)、\(a_0=a\)、\(a_t=\pi(s_t)\ (t\ge1)\)，并记对应的 \(H\) 步截断价值为
\[
Q_H^\pi(s,a)
=
\mathbb E\!\left[
\sum_{t=0}^{H-1}\gamma^t r(s_t,a_t)+\gamma^H V^\pi(s_H)
\right].
\]
相应地，在世界模型 \(\hat T\) 上定义模型内轨迹 \(\hat s_0=s\)、\(\hat a_0=a\)、\(\hat a_t=\pi(\hat s_t)\ (t\ge1)\)。一次模型 rollout 的截断回报记为

\[
\hat{R}_i(s,a)
=
\sum_{t=0}^{H-1} \gamma^t r(\hat{s}_t,\hat{a}_t)
\;+\;
\gamma^H V_\psi(\hat{s}_H).
\]

定义模型内期望回报
\[
\tilde Q_H^{\hat T,\pi,V_\psi}(s,a)
=
\mathbb E[\hat R_i(s,a)],
\]
以及 \(n\) 次样本平均估计量
\[
\hat{Q}_n(s,a) = \frac{1}{n} \sum_{i=1}^n \hat{R}_i(s,a).
\]

于是有如下误差分解：

\[
\hat{Q}_n(s,a) - Q^\pi_H(s,a)
=
\underbrace{\bigl(\hat Q_n(s,a)-\tilde Q_H^{\hat T,\pi,V_\psi}(s,a)\bigr)}_{\varepsilon_n(s,a)}
\;+\;
\underbrace{\bigl(\tilde Q_H^{\hat T,\pi,V_\psi}(s,a)-Q_H^\pi(s,a)\bigr)}_{b_H(s,a)}.
\]

其中，\(\varepsilon_n(s,a)\) 是样本平均相对于模型内期望回报的随机项；若进一步假设这些 rollout 回报样本独立同分布，或满足标准次高斯集中条件，则有 \(\varepsilon_n(s,a)=\mathcal O_p(n^{-1/2})\)。因此，命题 4 的关键在于刻画系统性偏差项 \(b_H(s,a)\) 如何随模型误差和规划深度变化。

\textbf{命题 4 的关键推导}：

\textbf{（一）由状态误差到回报偏差的一般上界。} 记闭环单步奖励为 \(\bar r_\pi(s):=r(s,\pi(s))\)，并假设：(1) \(\bar r_\pi\) 对状态是 \(L_r\)-Lipschitz 且真实终端值函数 \(V^\pi\) 是 \(L_V\)-Lipschitz 的；（2）第 5.2 节中的 \(L_f\) 表示 rollout 策略 \(\pi\) 诱导下闭环一步映射的有效 Lipschitz 常数；（3）终端价值网络在本文讨论的相关状态域上满足统一逼近误差
\[
|V_\psi(x)-V^\pi(x)|\le \epsilon_V
\]
再定义多步状态误差
\[
e_t := \mathbb E\bigl[\|\hat s_t-s_t\|\bigr].
\]
由于初始条件相同，即 \(\hat s_0=s_0=s\)、\(\hat a_0=a_0=a\)，故 \(t=0\) 项不产生状态失配。由三角不等式、Lipschitz 条件以及期望与求和可交换，可得

\[
\begin{aligned}
|b_H(s,a)|
&=
\left|
\mathbb E\!\left[
\sum_{t=0}^{H-1}\gamma^t \bigl(\bar r_\pi(\hat s_t)-\bar r_\pi(s_t)\bigr)
\;+\;
\gamma^H\bigl(V_\psi(\hat s_H)-V^\pi(s_H)\bigr)
\right]
\right| \\
&\le
\sum_{t=1}^{H-1}\gamma^t L_r\, e_t
\;+\;
\gamma^H\!\left(L_V e_H + \epsilon_V\right).
\end{aligned}
\]
因此，Q 偏差的阶数由多步状态误差 \(e_t\) 的传播方式直接决定。

\textbf{（二）BlackBox 模型的偏差来自误差的级联放大。} 由 §5.2 命题 2，若无结构约束的黑盒模型满足有效 Lipschitz 常数 \(L_f>1\)，且初始状态无误差 \(e_0=0\)，则其 \(t\) 步状态误差满足

\[
e_t^{\mathrm{BB}}
\le
\frac{L_f^t-1}{L_f-1}\,\epsilon_{\text{model}}
=
\mathcal O(L_f^t).
\]
代回上式可得
\[
\begin{aligned}
|b_H^{\mathrm{BB}}(s,a)|
&\le
\sum_{t=1}^{H-1}\gamma^t L_r\, e_t^{\mathrm{BB}}
\;+\;
\gamma^H\!\left(L_V e_H^{\mathrm{BB}}+\epsilon_V\right) \\
&=
\mathcal O\!\left(\sum_{t=1}^{H-1}(\gamma L_f)^t\right)
\;+\;
\mathcal O\!\left(\gamma^H L_f^H\right)
\;+\;
\mathcal O(\gamma^H\epsilon_V).
\end{aligned}
\]
特别地，当 \(\gamma L_f>1\) 时，上式主导项呈指数增长，因此可简写为
\[
\left|b_H^{\mathrm{BB}}(s,a)\right|
\le
C_{\mathrm{BB}}(\gamma L_f)^H,
\]
其中 \(C_{\mathrm{BB}}\) 吸收了单步模型误差、奖励与终端值的 Lipschitz 常数以及终端价值逼近误差等与 \(n\) 无关的常数项。

因此，增加样本数 \(n\) 只能减小 \(\varepsilon_n\)，无法消除由模型结构失配导致的 \(b_H^{\mathrm{BB}}\)；这正是正文所说的“不可约偏差”。

\textbf{（三）SD 模型的偏差保持有界，并在理想条件下消失。} 对结构化动力学模型，由 §5.2 命题 2，若其在工作区间内满足 \(0\le L_f<1\)，则同样在 \(e_0=0\) 下有

\[
e_t^{\mathrm{SD}}
\le
\frac{1-L_f^t}{1-L_f}\,\epsilon_{\text{model}}
\le
\frac{\epsilon_{\text{model}}}{1-L_f}.
\]
于是
\[
\begin{aligned}
|b_H^{\mathrm{SD}}(s,a)|
&\le
\sum_{t=1}^{H-1}\gamma^t L_r\, e_t^{\mathrm{SD}}
\;+\;
\gamma^H\!\left(L_V e_H^{\mathrm{SD}}+\epsilon_V\right) \\
&\le
\frac{L_r\gamma}{(1-\gamma)(1-L_f)}\,\epsilon_{\text{model}}
\;+\;
\frac{L_V}{1-L_f}\,\epsilon_{\text{model}}
\;+\;
\epsilon_V
\;=:\;
C_{\mathrm{SD}}.
\end{aligned}
\]
因此，SD 侧的系统性偏差被控制在与 \(H\) 和 \(n\) 都无关的常数量级内。

进一步地，若结构完全匹配、转移确定且终端价值估计无误差，即 \(\epsilon_{\text{model}}=0\) 且 \(\epsilon_V=0\)，则对所有 \(t\) 有 \(e_t^{\mathrm{SD}}=0\)，从而
\[
b_H^{\mathrm{SD}}(s,a)\equiv 0.
\]

\textbf{推论}：在相同的样本预算 \(n\) 下，随机项 \(\varepsilon_n\) 的衰减速度对两类方法是相同量级的；真正拉开差距的是系统性偏差项。BlackBox 模型对应的 \(b_H^{\mathrm{BB}}\) 会随规划深度恶化，而 SD 模型对应的 \(b_H^{\mathrm{SD}}\) 则保持有界，并在理想匹配条件下消失。这便严格化了正文 §5.4 的核心结论：SD-MCTS 的优势主要来自结构化动力学对不可约偏差的抑制，而不是来自 rollout 次数增加所带来的随机方差下降。
